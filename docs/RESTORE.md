# 台帳を戻すとき

控えは 3 段あります。上から順に使います。

| 控え | 置き場所 | 残る長さ | 中身 |
|---|---|---|---|
| D1 の巻き戻し | Cloudflare | 30 日 | 任意の時点の全部 |
| 毎日の控え | R2 の `backup/<日付>.json` | 90 日 | 全表（ファイルは入らない） |
| 週次の控え | ドライブ `Kura/塾/バックアップ` | 消すまで | 全表から秘密を外したものと、ファイル |

## 30 日以内の間違い

```bash
npx wrangler d1 time-travel info stepwise-v2 --timestamp <戻す時刻>
```

```bash
npx wrangler d1 time-travel restore stepwise-v2 --bookmark=<表示された値>
```

戻すとその時刻より後の記録が消えます。先に今の控えを取り、本人に確かめてから実行します。

## JSON の控えから戻す

1. 空のデータベースを作り、`cf/migrations-v2` を順に当てます。
2. トリガーの定義を控えて、すべて外します。「履歴は消せない」決まりが、戻す作業も断るためです。
3. マイグレーションが入れた `settings` と `termsVersions` の行を消します。
4. 外部キーの確かめを止め、控えの `tables` を表ごとに入れます。
5. トリガーを定義し直し、`pragma foreign_key_check` と `pragma integrity_check` を確かめます。件数を控えの表と比べます。

2026-11-05 にこの手順で 55 表 1,523 行が戻ることを確かめました。

## 週次の控えから戻したあとにすること

週次の控えには次のものが入っていません。

| 外したもの | 戻したあとにすること |
|---|---|
| スタッフと保護者のパスワードの暗号値 | 全員にパスワードを設定し直してもらう |
| 生徒の専用リンクの鍵 | 新しいリンクを発行する |
| 講師の口座番号 | 講師に入れ直してもらう |
| ログイン中の情報 | 全員がログインし直す |
| 送ったメールの本文 | 戻せない（送った記録は残る） |

ファイルは `ファイル/<id>_<名前>` を R2 の `f/<id>` へ戻します。
