### 第1条 指導の目的と契約者

<a id="article-1-item-1"></a>

1. ステップワイズ個別指導（代表者：麦倉優輔、所在地・教室所在地：埼玉県越谷市袋山1319-9、電話：080-6259-3025。以下「塾」）は、生徒の学力向上、基礎学力の定着、学習習慣の形成および目標達成を支援するために指導を行います。

<a id="article-1-item-2"></a>

2. 契約者は、受講申込書に記載する保護者その他受講契約を締結する権限を有する方です。以下「保護者」といいます。

<a id="article-1-item-3"></a>

3. 塾は誠実に指導しますが、成績向上、合格、資格取得その他一定の成果を保証するものではありません。

<a id="article-1-item-4"></a>

4. 生徒と保護者は、無理のない範囲で、宿題・復習などの家庭学習に協力するものとします。

### 第2条 契約書類と受講管理システム

<a id="article-2-item-1"></a>

1. 契約は本規約、受講条件書（通常指導）、双方が合意した受講条件書（特殊指導）、双方が合意した受講合意書および[第12条](#article-12)により確定した予約日時によります。

<a id="article-2-item-2"></a>

2. 受講条件書（通常指導）は、生徒・家庭ごとの継続的な指導条件と通常指導の基準単価を記録し、双方で合意する書面または電子記録です。

<a id="article-2-item-3"></a>

3. 受講条件書（特殊指導）は、[第5条](#article-5)の特殊指導について、その内容と範囲、特殊指導の基準単価を定め、双方で合意する書面または電子記録です。

<a id="article-2-item-4"></a>

4. 受講合意書は、保護者または塾が案を提示し、双方が合意した指導の実施範囲と適用単価を記録する書面または電子記録です。

<a id="article-2-item-5"></a>

5. 塾は、授業や契約に関する情報を確認・管理するため、オンラインの受講管理システムを利用します。主な画面は次のとおりです。

   - 保護者ページ：保護者が受講条件書・受講合意書の確認や承認、授業記録・請求の確認などを行う画面です。
   - 日程調整カレンダー：授業日時や学校行事・試験等の予定を確認・調整する画面です。授業予定を「調整中」「確認待ち」「確定」に分けて表示し、[第12条](#article-12)により確定した授業を予約として扱います。

   塾は利用方法を案内します。利用できない場合の連絡方法は[第23条](#article-23)によります。

<a id="article-3"></a>

### 第3条 契約期間と更新

<a id="article-3-item-1"></a>

1. 受講契約は暦の月ごとに結びます。初月が月途中の場合は合意した開始日から月末までです。対象月の開始前でも、その対象月の受講合意書に双方が合意すれば、その月の受講契約が成立します。

<a id="article-3-item-2"></a>

2. 契約は自動更新しません。翌月分について双方の合意がなければ翌月の受講契約は成立しません。複数月の学習計画はまとめて作れますが、月ごとの対象期間と合意を区別します。先の学習方針への同意だけで将来月の受講合意書が成立するものではありません。

## 第2章 指導内容・条件・料金

### 第4条 指導形態と担当講師

<a id="article-4-item-1"></a>

1. 対象となる科目と具体的な指導内容は、生徒の学年、目標、理解状況を踏まえ、受講条件書（通常指導）および受講合意書で定めます。

<a id="article-4-item-2"></a>

2. 指導は、受講条件書（通常指導）で合意した教室指導、オンライン指導、またはその組合せで行います。

<a id="article-4-item-3"></a>

3. 教室指導は講師1名につき生徒最大2名を基本とし、最大2名の形態で実際の参加者が1名となっても、料金は変わりません。

<a id="article-4-item-4"></a>

4. 教室指導で1対1のみの授業は、当面行いません。希望がある場合は、内容と料金を別途相談し、合意したうえで行います。

<a id="article-4-item-5"></a>

5. オンライン指導は当面1対1で行い、料金は受講条件書（通常指導）で合意します。既存のオンライン1対1契約に、この改定だけを理由として新たな追加料金を適用しません。

<a id="article-4-item-6"></a>

6. 代表者または塾が指導を任せた講師が担当します。担当講師の変更は事前に通知します。指導形態・人数・時間・料金の変更には、説明して保護者の承認を得ます。

<a id="article-4-item-7"></a>

7. 生徒側で端末、通信環境、カメラ、マイク等をご準備ください。使用サービスと接続方法は事前に案内し、必要に応じて接続確認を行います。

<a id="article-5"></a>

### 第5条 通常指導と特殊指導

<a id="article-5-item-1"></a>

1. 指導は原則として「通常指導」とし、その指導に通常必要な準備を含みます。「特殊指導」は、第3項に当たる場合に、[第6条](#article-6)の事前説明と保護者の承認を経て例外的に行います。

<a id="article-5-item-2"></a>

2. 準備の負担は、総時間だけでなく、次のように生徒1人・授業1回当たりで判断します。

   - 同じ準備を複数の生徒への指導に直接活用できる場合は、共通する準備時間をその生徒数に分配して考えます。
   - 継続的な学習の延長として定期テスト・模試・入試の対策を行う場合は、その準備の負担を、関連する一連の指導の回数に分配して考えます。

<a id="article-5-item-3"></a>

3. 特殊指導は、前項の方法で考えても、生徒1人・授業1回当たりの準備の負担が通常指導で想定する範囲を大きく超える場合に限ります。例として、演習を授業時間に含めず、毎回異なる試験問題の解説のみを行い、その都度個別の準備を必要とする指導や、英検準1級以上の対策などがあります。名称や級、問題の難しさだけで判断せず、塾が個別に判断して事前にお伝えします。

<a id="article-5-item-4"></a>

4. 通常指導の延長に当たる試験対策や問題解説は特殊指導にしません。代表的な例として、埼玉県公立高校入試の問題解説、英検2級までの対策、数検・漢検の対策は通常指導に含めます。

<a id="article-6"></a>

### 第6条 受講条件書の記載事項と合意

<a id="article-6-item-1"></a>

1. 受講条件書（通常指導）には、対象生徒、指導科目、教室・オンラインの別、指導人数、通常指導（[第5条](#article-5)）の授業時間と通常指導の基準単価（税込）、割引・追加料金、適用期間、特別に合意した条件を記載します。

<a id="article-6-item-2"></a>

2. 受講条件書（特殊指導）には、特殊指導の名称、指導の目的、内容と範囲、通常指導との違い、必要な準備、1回の時間と特殊指導の基準単価（税込）、対象期間、特別に合意した条件を記載します。

<a id="article-6-item-3"></a>

3. 特殊指導は、塾が受講条件書（特殊指導）（案）で[第6条第2項](#article-6-item-2)の事項を具体的に提示し、保護者の承認を得た範囲と期間でだけ行います。承認は保護者ページ上の操作、書面、LINE・メール等で確認し、塾は承認の日時と方法を記録します。承認がない場合、特殊指導として扱わず、特殊指導の基準単価を適用しません。

<a id="article-6-item-4"></a>

4. 特殊指導の内容、基準単価または期間を変える場合は、新しい受講条件書（特殊指導）で改めて承認を得ます。

<a id="article-7"></a>

### 第7条 料金の根拠と計算

<a id="article-7-item-1"></a>

1. 受講条件書（通常指導）で合意した「通常指導の基準単価」と、受講条件書（特殊指導）で合意した「特殊指導の基準単価」を、共通して「基準単価」といいます。各回に使用する「適用単価」は、その指導に対応する対象月の承認済み基準単価を上限として、受講合意書で合意します。単価は税込とし、授業時間が異なる場合は同じ時間に換算して比較します。

<a id="article-7-item-2"></a>

2. 授業料は、通常指導・特殊指導とも適用単価に基づき計算し、準備時間を別途加算しません。実施時間が予約時間と異なる場合は、適用単価を時間に比例して計算し、1円未満を切り捨てます。塾都合の延長には追加料金を請求しません。通信障害により中止する場合は、[第19条](#article-19)の特則によります。

<a id="article-7-item-3"></a>

3. 体験・割引は金額、適用期間、回数、終了後の条件を示します。基準単価、適用単価その他の料金を変更する場合も、変更内容と適用時期について事前承認を得ます。承認のない月への遡及的な値上げは行いません。

<a id="article-7-item-4"></a>

4. 教材の費用は[第8条](#article-8)によります。

<a id="article-8"></a>

### 第8条 教材と配布資料

<a id="article-8-item-1"></a>

1. 指導に必要な教材は、原則として塾が手配します。塾が指導上必要と判断して用意する教材の費用は授業料に含め、継続使用する教材や塾専用教材も含め、教材費を別途請求しません。

<a id="article-8-item-2"></a>

2. 保護者または生徒の強い希望により、前項の教材とは別に指定教材を用意する場合は、次のいずれかとします。

   - 保護者側で購入・用意する。
   - 塾に購入・手配を依頼し、購入にかかる実費を「教材手配代行費用」として支払う。

   塾が手配する場合は、教材名と負担額を示し、保護者の事前承諾を得てから、ご家庭に代わって購入します。生徒の希望だけで追加費用を確定しません。

<a id="article-8-item-3"></a>

3. 教材・資料は当面、配布のみとし、貸与は行いません。貸与を行う場合は、範囲・返却条件・紛失時の扱いを事前に合意します。教材を用意したことを理由に翌月以降の受講を義務付けたり、塾負担とした教材費を退会時にさかのぼって請求したりしません。

<a id="article-8-item-4"></a>

4. 教材・配布資料は生徒本人の学習のために利用し、許可なく販売・公開・第三者へ提供しないでください。法令上認められる利用まで制限する趣旨ではありません。

### 第9条 受講合意書の提案と記載事項

<a id="article-9-item-1"></a>

1. 塾から提案する場合は、原則として前月20日ごろまでに翌月の案を提示します。保護者からの提案も受け付けます。

<a id="article-9-item-2"></a>

2. 受講合意書の案には、対象生徒、対象月と対象期間（開始日・終了日）、科目ごとの具体的な授業内容と回数、各回の時間、適用単価（税込）および予定総額を示し、各回が通常指導か特殊指導（その名称）かを記載します。

<a id="article-9-item-3"></a>

3. 合意前は「受講合意書（案）」として区別します。

<a id="article-10"></a>

### 第10条 受講内容の合意方法と記録

<a id="article-10-item-1"></a>

1. 合意は、保護者ページでの承認操作、LINE・メールのやり取り、面談・電話等で確認します。塾は提案者、双方が合意した同一の版、双方の意思表示とその日時・経路を記録します。

<a id="article-10-item-2"></a>

2. 面談・電話で合意する場合も、できる限り授業実施前に、保護者ページ・LINE・メール等で、承認のやり取りを後で見返せる形で記録に残します。授業実施前に記録を残す時間が十分にない場合も、具体的な授業内容について口頭で明示的な承認を得てから授業を行います。塾は合意した内容と日時を記録し、速やかに控えを送ります。事前の承認なしに授業を行い、授業後に承認を求めることはしません。

<a id="article-11"></a>

### 第11条 授業の実施承認と実施できる範囲

<a id="article-11-item-1"></a>

1. 受講合意書の案は、保護者または塾のいずれからも提示できます。授業の実施には、保護者と塾の双方による事前の明示的な合意を必要とします。塾は、合意した受講合意書に定める期間内に、その科目と回数の範囲に限って授業を実施できます。「授業方針に賛成する」などの一般的な意思表示だけでは、具体的な授業の実施承認とは扱いません。

<a id="article-11-item-2"></a>

2. 特殊指導の月ごとの回数は、通常指導と同じく受講合意書で合意します。受講条件書（特殊指導）の承認だけでは、授業の実施承認とはなりません。

<a id="article-11-item-3"></a>

3. 合意した回数は、対象期間内に実施可能な授業回数の上限です。受講合意書に合意した時点で、授業の事前購入、全回数の受講義務、その回数分の受講の保証、未実施分の繰越権が生じるものではありません。

<a id="article-11-item-4"></a>

4. 対象期間外の実施、回数の追加、科目の追加・変更その他の条件変更は、変更版または追加の受講合意書について事前に双方が合意した場合に限り行います。

<a id="article-12"></a>

### 第12条 日程調整カレンダーによる日時の確定と予約

<a id="article-12-item-1"></a>

1. [第2条](#article-2)の受講管理システムにある日程調整カレンダーで、受講合意書で実施承認された授業の具体的な実施日時を調整し、確定（予約）します。学校行事・試験等の予定も、日程調整の参考として登録できます。

<a id="article-12-item-2"></a>

2. 授業予定は、次の段階で扱います。

   - 下書き：塾が準備している段階です。保護者・生徒には表示しません。
   - 調整中：塾と保護者が日時を相談している段階です。保護者・生徒にも表示しますが、予約ではありません。回答の締め切りはなく、時間が経っても自動で確定しません。
   - 確認待ち：塾が日時と回答の締め切りを示し、その日時で確定することを提案している段階です。保護者・生徒にも表示します。この段階では、まだ予約は成立していません。
   - 確定：第4項または第5項により日時が確定し、予約として成立した授業です。

<a id="article-12-item-3"></a>

3. 予約は、双方が合意した受講合意書の期間・科目・回数・時間の範囲に限ります。カレンダー操作だけで、合意した期間・科目・回数の範囲を広げたり、適用単価を上げたりしません。日時一覧を受講合意書に添えて同時に承認した場合は、その日時を予約として記録できます。

<a id="article-12-item-4"></a>

4. 塾と保護者が日時に合意した場合は、その時点で確定します。確認待ちの授業について、保護者が保護者ページで「この日程で大丈夫」など日時への同意を明示する操作をした場合も、提示された日時に合意したものとして確定します。LINE・メール・面談・電話等で日時に合意した場合は、[第23条第2項](#article-23-item-2)に従って記録します。

<a id="article-12-item-5"></a>

5. 承認済みの受講合意書の範囲で塾が日時を提案する場合、塾はその授業を確認待ちとし、保護者ページ・LINE等で、日時、回答の締め切り、および締め切りまでに変更・お休みの連絡がなければその日時で確定することを明示してお知らせします。締め切りまでに保護者から変更・お休みの連絡がなければ、提案した日時で確定します。締め切りより前に前項の合意があった場合は、その時点で確定します。締め切りは、判断に十分な余裕があるように、原則としてお知らせから3日以上あと、かつ授業日の2日前までに置きます。

<a id="article-12-item-6"></a>

6. 前項の締め切りを置く余裕がない直前の提案は、無回答や期限経過だけでは確定せず、第4項の合意により確定します。塾からのお知らせがなかった場合、または判断の余裕がないまま直前に提案した場合は、保護者はその予約を無効（取消し）にでき、キャンセル料金はかかりません。ただし、事前に当事者の間でその日時について相談して同意していた場合（翌日の授業を希望して登録した場合など）は、塾からのお知らせが直前だったことだけを理由に、予約を無効にして無料で取り消すことはできません。

<a id="article-12-item-7"></a>

7. 受講合意書が未承認の場合は、その案や日時候補に「未承認の案」などと表示し、確定した授業と区別します。案を読んだこと、返信しなかったこと、回答期限が過ぎたことだけでは、その期間・科目・回数・適用単価で授業を行う承認にはなりません。第5項の「連絡がなければ日時が確定する」扱いは、受講合意書で既に承認された授業の日時調整に限ります。

<a id="article-12-item-8"></a>

8. 調整中・確認待ちの授業は予約ではないため、取りやめてもキャンセル料金はかかりません。

<a id="article-12-item-9"></a>

9. 「確定」は予約が成立したことを示すものであり、それだけでキャンセル料金が発生するものではありません。確定した授業も、[第13条](#article-13)により前日23時までは無料で取り消せます。前日23時を過ぎてから新しく予約する場合は、その時点から適用されるキャンセルポリシーも示して承認を得ます。

<a id="article-12-item-10"></a>

10. 将来の固定曜日・時刻の枠は、別途約束しない限り保証しません。

<a id="chapter-4"></a>

## 第4章 欠席・遅刻・変更・中止と費用

[第13条 予約のお休みと新しい予約](#article-13) · [第14条 キャンセル料金と負担率](#article-14) · [第15条 同日の開始を遅らせて予約し直す場合](#article-15) · [第16条 遅刻した場合](#article-16) · [第17条 やむを得ない事情による免除](#article-17) · [第18条 塾の都合による変更と休講](#article-18) · [第19条 オンライン授業の接続不良による中止](#article-19)

**キャンセルポリシー（第13～18条）と通信中止の特則（第19条）**

授業の取消しや欠席・遅刻・日時変更により、予約していた授業時間のうち実施されなかった時間にかかる費用を「キャンセル料金」とします。無料で取り消せる期限、負担率、免除、塾側の都合による例外は以下に定めます。オンライン授業が接続不良で中止になった場合は、[第13～18条](#article-13)ではなく[第19条](#article-19)で計算します。[第19条](#article-19)で計算した時間に、この章のキャンセル料金を重ねてかけることはありません。

<a id="article-13"></a>

### 第13条 予約のお休みと新しい予約

<a id="article-13-item-1"></a>

1. 保護者は、授業日の前日23時まで、予約した授業を無料でお休み（取消し）にできます。行わない授業の授業料もキャンセル料金もかかりません。塾の承諾がなくても、キャンセルは成立します。保護者が受講条件書（通常指導）で生徒本人からの連絡を認めている場合は、生徒本人も同じ連絡ができます。キャンセル料金が生じる連絡は、保護者にもお知らせします。

<a id="article-13-item-2"></a>

2. お休みの連絡が指定のページ・LINE等の窓口に到達した時点で、元の予約の取消しが成立します。担当者による確認や記録が後になった場合も、連絡が到達した時刻にさかのぼって処理し、その時刻をもとにキャンセル料金を計算します。

<a id="article-13-item-3"></a>

3. 予約済みの授業を取り消して、別の日または別の時刻に授業を希望する場合は、元の授業とは独立した新しい予約として、[第12条](#article-12)に従って申し込むことができます。取り消した授業の予約と、新しく成立した授業の予約は、別々のものとして扱います。

<a id="article-13-item-4"></a>

4. お休みの意思を明示しない連絡（別の日時が空いているかの問い合わせなど）は、予約の取消しとして扱いません。元の予約を取り消して別の日時で授業を希望する場合は、元の予約を取り消す旨を必ずお伝えください。

<a id="article-13-item-5"></a>

5. 予約を取り消した場合、取り消した分の授業を別の日時で実施することは保証しません。講師や教室の空きがないときは、新しい予約をお受けできないことがあります。

<a id="article-13-item-6"></a>

6. 前日23時を過ぎてから元の予約を取り消す場合、または予約していた日時の授業が実施されなかった場合は、原則としてキャンセル料金が発生し、[第14条](#article-14)によります。取り消した予約の代わりに別の予約をした場合であっても、元の予約の取消しについてキャンセル料金が発生します。同日の開始を遅らせる場合の未実施時間は[第15条](#article-15)によります。

<a id="article-14"></a>

### 第14条 キャンセル料金と負担率

<a id="article-14-item-1"></a>

1. 前日23時を過ぎてから、生徒側の事情で予約した授業の全部または一部が行われなかった場合、行われなかった時間（以下「未実施時間」）についてキャンセル料金がかかります。未実施時間は、元の予約時間の範囲内で数えます。

<a id="article-14-item-2"></a>

2. キャンセル料金は「未実施時間に相当する授業料×負担率」で計算し、10円未満を切り捨てます。「未実施時間に相当する授業料」とは、その予約で合意した授業料と時間をもとに、未実施時間の分を時間に比例して計算した額です。例えば、予約していた90分4,500円のうち30分が未実施となった場合、相当する授業料は1,500円です。

<a id="article-14-item-3"></a>

3. 負担率は、未実施時間に相当する授業料のうち保護者がキャンセル料金として負担する割合であり、連絡を受け付けた時刻によって、100％を上限として次のとおり定めます。

| 連絡の時刻 | 負担率 |
| --- | --- |
| 前日23時まで | 0％ |
| 前日23時を過ぎ、開始3時間前まで | 25％ |
| 開始3時間前を過ぎ、開始時刻より前 | 100％－75％×開始までの残り分数÷180 |
| 開始時刻以降、または連絡なし | 100％ |

<a id="article-14-item-4"></a>

4. 前日23時ちょうどまでを無料とし、この規定を他の時間帯区分より先に適用します。ページ・LINE・メール等の受付時刻を使い、塾が読んだ時刻や後から入力した時刻を理由に負担率を引き上げません。

<a id="article-14-item-5"></a>

5. 同じ時間に、授業料とキャンセル料金の両方をかけることはありません。明細では、実施した分の授業料とキャンセル料金を分けて示します。

<a id="article-14-item-6"></a>

6. キャンセル料金は予約ごとに計算します。別日時の新しい予約は別の予約として扱い、新しい予約を取り消した場合も、その予約について本条により計算します。複数の連絡や変更が重なる細かな場面は、事実を確認して個別にご説明します。

<a id="article-15"></a>

### 第15条 同日の開始を遅らせて予約し直す場合

<a id="article-15-item-1"></a>

1. 元の予約のお休みは[第13条](#article-13)により受け付けます。同日の別時刻に授業を希望する場合は、終了時刻、担当講師、他の授業を確認し、新しい予約について双方で合意します。

<a id="article-15-item-2"></a>

2. 無料期限後の予約変更で、元の予約時間と新しい予約時間が重なる場合、元の予約時間のうち実際に指導した時間を除いた未実施時間にだけ、[第14条](#article-14)のキャンセル料金を適用します。実施分の授業料は[第7条](#article-7)によります。元の予約枠の同じ時間に授業料とキャンセル料金を重ねません。

<a id="article-15-item-3"></a>

3. 新しい予約が成立しなかった場合でも、明示的に取り消した元の予約は復活しません。元の予約を残したまま日時を相談していた場合は、元の予約に遅刻・欠席した分を[第14・16条](#article-14)により扱います。

<a id="article-15-item-4"></a>

4. 変更後の日時、元の予約の未実施時間、新しい予約の授業料と見込み合計額を示し、実施前に承諾を得ます。

<a id="article-16"></a>

### 第16条 遅刻した場合

<a id="article-16-item-1"></a>

1. 遅れることが分かったら、その時点で到着の見込みをお知らせください。連絡がない場合の負担率は100％です。

<a id="article-16-item-2"></a>

2. [第15条](#article-15)で開始を変更した場合を除き、遅刻しても授業は予定の終了時刻に終わります。

<a id="article-16-item-3"></a>

3. 遅れた時間は未実施時間として[第14条](#article-14)で計算し、実際に行った時間は授業料として計算します。

<a id="article-16-item-4"></a>

4. 到着の見込みよりさらに遅れた分は、改めて連絡を受けた時刻の負担率、追加連絡がなければ100％で計算します。

<a id="article-16-item-5"></a>

5. 遅刻・当日の変更が続く場合は、無理なく通える曜日・時間について保護者と相談します。

<a id="article-17"></a>

### 第17条 やむを得ない事情による免除

<a id="article-17-item-1"></a>

1. 無料取消し期限を過ぎた取消しや欠席・遅刻には、原則としてキャンセル料金が発生します。ただし、次の3条件をすべて満たす場合は、申請により個別に免除することがあります。

   - (1) やむを得ない事情により、予定していた授業の全部または一部を受講できなかったこと。
   - (2) 受講できない、または遅れることが分かった時点で、できるだけ早く塾へ連絡したこと。
   - (3) 説明や確認資料により、その事情を塾が確認できること。

   例えば、授業の1時間前には到着が遅れると分かっており、連絡できる状況だったにもかかわらず、開始直前まで連絡しなかった場合は、(2)を満たしません。救急搬送等で連絡自体ができない場合は、第2項の扱いによります。実施分の授業料は免除対象に含みません。

<a id="article-17-item-2"></a>

2. 対象となる事情の例は、公共交通の運休・遅延、親族の葬儀、災害、重篤な体調不良で受診した場合などです。通常の体調不良は対象外です。申請窓口・時期の目安・確認資料・救急搬送等で連絡自体ができない場合の扱いは、[キャンセル料金の免除申請のご案内](https://www.stepwise-education.jp/terms/2026-11-20261012-r3/waiver/)で共通に示し、個別の事情を確認します。

<a id="article-17-item-3"></a>

3. 資料は確認に必要な範囲に限り、病名等の不要な情報は隠してください。取得目的、提出窓口、保存期間は事前に案内します。

<a id="article-17-item-4"></a>

4. 塾は確認結果と理由を回答します。保留・訂正・返金は[第21・22条](#article-21)によります。対象表にない事情も相談できます。

<a id="article-18"></a>

### 第18条 塾の都合による変更と休講

<a id="article-18-item-1"></a>

1. 塾の都合で日時を変更するときは、できるだけ早く連絡し、変更後の日時を相談します。保護者・生徒にキャンセル料金はかかりません。

<a id="article-18-item-2"></a>

2. 塾の都合で行えなかった時間の授業料は請求しません。別の日に授業を行う場合は、その実施分について合意した料金を請求します。

<a id="article-18-item-3"></a>

3. 塾の都合による休講と、生徒側の都合による取消は、記録と明細を分けます。

<a id="article-19"></a>

### 第19条 オンライン授業の接続不良による中止

<a id="article-19-item-1"></a>

1. 接続不良によって授業の継続が困難な場合は、授業を中止できます。中止する旨を相手方へ知らせ、中止時刻を記録します。接続手段が使えない場合は、LINEまたはメール等で連絡します。

<a id="article-19-item-2"></a>

2. 生徒側の通信環境・端末等の不具合で中止する場合、予定開始時刻から中止時刻までは通常の授業料で計算します。接続の確認・復旧に費やした時間を含みます。中止時刻から予定終了時刻までは、その時間に相当する授業料の30％をキャンセル料金として計算します。中止後は授業のために待機し続ける必要はありません。

<a id="article-19-item-3"></a>

3. 第2項の通常料金部分は1円未満、30％部分は10円未満を切り捨てます。同じ時間に[第14条](#article-14)の通常キャンセル料金や他の授業料を重ねません。後日行う授業は別の予約として合意します。

<a id="article-19-item-4"></a>

4. 塾側の不具合、または利用サービス全体の障害によって実施できなかった時間には、授業料もキャンセル料金も請求しません。中止前であっても、障害により実施できなかった時間を通常料金へ含めません。実際に実施した分だけを計算します。

<a id="article-19-item-5"></a>

5. 開始前の中止、短時間の切断、原因が分からない場合は、原因不明のまま生徒側の不具合と扱わず、事実を確認して個別にご説明します。

## 第5章 請求・支払い・見直し・返金

[第20条 請求と支払い](#article-20) · [第21条 キャンセル料金の確認・見直しと支払い](#article-21) · [第22条 請求の訂正と返金](#article-22)

<a id="article-20"></a>

### 第20条 請求と支払い

<a id="article-20-item-1"></a>

1. 当月に実施した授業の料金、キャンセル料金、および[第8条第2項](#article-8-item-2)により事前合意した教材手配代行費用を集計します。家族で合算する場合も、生徒別の内訳を示します。

<a id="article-20-item-2"></a>

2. 原則として翌月3日に請求を確定し、保護者ページでお知らせします。1日と2日は塾が内容を確認する期間です。

<a id="article-20-item-3"></a>

3. 授業料等は、原則として銀行振込でお支払いください。特別な事情により銀行振込が難しい場合は、事前にご相談ください。塾が個別に承認した場合は、別途合意した方法でお支払いいただけます。銀行振込の手数料は、振込を行う保護者が負担します。支払期限は請求が確定した月の15日です。15日が土日祝日の場合は翌営業日です。

<a id="article-20-item-4"></a>

4. 支払期限までの支払いが難しい場合は、事前にご相談ください。連絡なく未払いが続く場合は、連絡・確認のうえ、授業の一時停止などを検討します。

<a id="article-21"></a>

### 第21条 キャンセル料金の確認・見直しと支払い

<a id="article-21-item-1"></a>

1. 保護者は、キャンセル料金の計算や料金がかかる条件、法令上請求できるかどうかに疑問がある場合、対象の授業と疑問の内容を示し、保護者ページまたは指定のLINE等から説明・見直しを申し出ることができます。法令名を調べたり、専門家の意見書を用意したりする必要はありません。

<a id="article-21-item-2"></a>

2. キャンセル料金の免除申請の審査中、または第1項の申出について塾が確認・回答するまでの間は、対象のキャンセル料金の支払いを保留します。それ以外の争いのない金額は、通常の期限内にお支払いいただきます。

<a id="article-21-item-3"></a>

3. 塾は第1項の申出を受け付け、事実関係と料金の計算根拠を確認します。受付から7日以内を目安に、確認結果と理由を、保護者ページ・LINE・メール等の後で見返せる方法で回答します。

<a id="article-21-item-4"></a>

4. 請求に誤りがある場合、または法令上請求できない部分がある場合は、その部分を訂正・除外します。それ以外の場合も、個別の事情を考慮し、キャンセル料金の全部または一部を減額・免除することがあります。

<a id="article-21-item-5"></a>

5. 塾が確認の結果、キャンセル料金の全部または一部を請求すると判断した場合は、請求する理由、金額と支払期限を改めてお知らせします。

<a id="article-21-item-6"></a>

6. 回答後に請求する金額は、次の請求（翌月15日期限）にまとめます。支払済みの場合は[第22条第1項](#article-22-item-1)に従って精算します。

<a id="article-21-item-7"></a>

7. 塾が請求すると回答した場合でも、法令上無効な部分は支払う必要がありません。これには塾の了承を必要としません。

<a id="article-21-item-8"></a>

8. 保護者は、塾への申出や回答の有無にかかわらず、消費生活センター等への相談や裁判などの紛争解決手続を利用できます。本条の手続によって、これらを含む保護者の法令上の権利を制限しません。

<a id="article-22"></a>

### 第22条 請求の訂正と返金

<a id="article-22-item-1"></a>

1. 確定後の訂正は、元の請求と訂正理由を残して通知します。支払済みの請求額が減額された場合は、払い過ぎた差額を、原則として翌月の請求への充当で精算します。保護者が振込を希望する場合、または翌月の請求がない・請求額を上回るなどの理由で翌月の請求に充当できない差額がある場合は、その返金額を減額が確定した月の翌月15日までに振り込みます。塾から返金する場合の振込手数料は、塾が負担します。

## 第6章 連絡・安全・情報の取り扱い

[第23条 連絡方法と生徒本人からの連絡](#article-23) · [第24条 保護者ページの利用](#article-24) · [第25条 教室利用・安全と禁止事項](#article-25) · [第26条 情報と録音の取り扱い](#article-26) · [第27条 実績や口コミの広報利用](#article-27)

### 第23条 連絡方法と生徒本人からの連絡

<a id="article-23-item-2"></a>

2. 日程、料金、受講終了など重要な内容は、双方が確認できる方法で記録します。電話・対面で決めた内容も、塾から控えを示します。

<a id="article-23-item-3"></a>

### 第24条 保護者ページの利用

<a id="article-24-item-1"></a>

<a id="article-24-item-2"></a>

<a id="article-24-item-3"></a>

3. 設定・再設定の方法はページ等で案内します。利用できない場合の連絡手段は[第23条](#article-23)によります。

<a id="article-24-item-4"></a>

4. アカウント共有等があったことだけを理由に、塾の責任を一律に免除するものではありません。

<a id="article-25"></a>

### 第25条 教室利用・安全と禁止事項

<a id="article-25-item-1"></a>

1. 塾は生徒の安全確保に努めます。生徒は設備・備品を適切に使用し、危険な行為をしないでください。

<a id="article-25-item-2"></a>

2. 体調不良時は無理に受講せず、早めにご連絡ください。緊急時の連絡先を塾にお知らせください。

<a id="article-25-item-3"></a>

3. 故意または重大な過失による設備等の破損・紛失については、事情を確認して相当額の負担を求めることがあります。

<a id="article-25-item-4"></a>

4. 暴力、暴言、威圧、著しい迷惑行為、許可のない授業の録音・録画・撮影・配信・公開、教材の不正利用など、指導や他者の権利を侵害する行為は禁止します。

<a id="article-25-item-5"></a>

5. 事故等の責任は原因と法令に基づき判断し、本規約によって塾の法令上の責任を一律に免除するものではありません。

<a id="article-26"></a>

### 第26条 情報と録音の取り扱い

<a id="article-26-item-1"></a>

1. 面談等の録音は当面行いません。行う場合は、聞き違いや記録漏れを防ぎ、ご家庭の希望・課題や面談で決めたことを次の指導計画・相談に正確に引き継ぐために利用します。目的・保存・閲覧の範囲を事前に説明し、同意を得てから行います。

<a id="article-26-item-2"></a>

2. 氏名・学年・学校・連絡先、成績、授業・宿題の記録、契約・請求・入金の記録、および第1項の録音を、次の目的に利用します。

   - 指導・学習支援、指導計画の提案・見直し
   - 次回面談の準備、連絡
   - 契約・請求の管理

<a id="article-26-item-3"></a>

3. 管理にはCloudflare（台帳・ファイルの保管）およびGoogle（メール・カレンダー）の外部サービスを利用します。

<a id="article-26-item-4"></a>

4. 講師には指導に必要な担当生徒の情報を共有し、料金・請求や免除申請の受診資料を、指導に不要な講師へ見せない運用とします。

<a id="article-26-item-5"></a>

5. 法令に基づく場合や適法な業務委託等を除き、同意なく個人情報を第三者に提供しません。必要な安全管理を行い、保存期間を定めます。

<a id="article-26-item-6"></a>

6. 記録に誤りがある場合は訂正を申し出ることができます。契約終了後の契約・請求記録等は、精算への対応および税務関係法令に基づく保存のため、記録の種類に応じて必要な期間（最長7年）保管します。免除の確認に使った受診記録などの資料は、確認が済み次第速やかに削除します。

### 第27条 実績や口コミの広報利用

<a id="article-27-item-1"></a>

### 第28条 受講の終了と予定済み授業

<a id="article-28-item-1"></a>

1. 保護者は、ページ・LINE・メール等で受講終了を申し出ることができます。翌月の受講合意書について双方が合意しない場合、翌月の受講契約は成立しません。

<a id="article-28-item-2"></a>

2. 終了の申出があっても、保護者が希望する場合は、既に実施承認・予約されている授業を受講できます。塾は、受講を希望する予約と取り消す予約、最終受講日を確認します。

<a id="article-28-item-3"></a>

3. 塾が翌月以降の継続を行えない場合は、原則1か月前までに連絡します。急病・事故等は分かり次第連絡します。

<a id="article-28-item-4"></a>

4. 精算するのは、実施した授業の授業料、取り消した予約にキャンセルポリシーが適用される場合のキャンセル料金、および[第8条第2項](#article-8-item-2)により事前合意した教材手配代行費用です。これら以外の解約金・退会金等は一切請求しません。

<a id="article-28-item-5"></a>

5. 取り消す予約は[第13～18条](#article-13)に従います。前日23時までに取消しを受け付けた予約に、終了の申出を理由として新たな料金を加算しません。

<a id="article-28-item-6"></a>

6. 対象期間の途中で特殊指導をやめる場合、特殊指導の授業料は実施した分だけを精算し、残期間の授業料や終了自体に対する解約金は請求しません。予約済みの授業を取り消す場合は、第4・5項に従い、通常指導と同じキャンセルポリシーを適用します。

### 第29条 契約違反による受講停止と解除

<a id="article-29-item-1"></a>

1. 契約違反がある場合は、相当な期間を定めて是正を求め、改善されないときに契約を解除できます。

<a id="article-29-item-2"></a>

2. 暴力など安全や信頼関係に重大な支障を与える場合は、直ちに受講を停止し、契約を解除することがあります。具体的な適用は事情に応じて判断します。

<a id="article-29-item-3"></a>

3. 終了時の料金は[第28条](#article-28)に従い精算します。

### 第30条 合意済み条件の変更

<a id="article-30-item-1"></a>

1. 基準単価・適用単価や指導人数など合意済みの条件を変更する場合は、変更箇所と適用時期を示して改めて保護者の承認を得ます。新しい受講合意書の案の送付やカレンダーへの入力だけでは条件を変更できません。

<a id="article-31"></a>

### 第31条 規約の版と変更への同意

<a id="article-31-item-1"></a>

1. 適用する規約は、保護者が同意した版の全文です。掲載ページを更新したことだけで、過去に同意した内容を置き換えません。

<a id="article-31-item-2"></a>

2. 塾は同意した版、対象となる受講合意書、同意者、日時、方法を保護者ページに記録し、保護者はいつでも同じ内容を保護者ページで確認できます（控え）。記録は、精算への対応および税務関係法令に基づく保存のため、記録の種類に応じて必要な期間（最長7年）保管します。

<a id="article-31-item-3"></a>

3. 条件を変更する場合は、変更点と適用時期を翌月の受講合意書の案等とともに示し、同意を得た契約から適用します。

<a id="article-31-item-4"></a>

4. 同意しない場合、変更後の条件による契約は成立しません。受講継続の可否や終了日を確認し、既に成立している契約と精算は従前の合意に従います。

<a id="article-31-item-5"></a>

5. この版は2026年11月1日から適用します。適用日より前に成立した契約と精算は、従前の合意によります。

## 別表1 キャンセル料金と合計料金の例

90分・4,500円、18時開始・19時30分終了の授業の例です。実施分の授業料は1円未満、キャンセル料金は10円未満を切り捨てます。

| --- | --- | --- | --- | --- |
| 前日23時まで | 0％ | 0円 | 0円 | 0円 |
| 前日23時を過ぎ当日15時まで | 25％ | 0円 | 1,120円 | 1,120円 |
| 当日16時 | 50％ | 0円 | 2,250円 | 2,250円 |

| 当日17時30分 | 87.5％ | 0円 | 3,930円 | 3,930円 |
| 当日18時以降または連絡なし | 100％ | 0円 | 4,500円 | 4,500円 |




| 実施した場合の例 | 授業料 | キャンセル料金 | 合計 |
| --- | --- | --- | --- |
| 17時に30分遅らせる連絡、塾が承諾し18時30分から90分実施 | 4,500円 | 1,120円 | 5,620円 |

## 別表2 接続不良による中止の計算例（第19条）

生徒側の接続不良により90分4,500円の授業を開始30分後に中止した場合、開始から中止まで1,500円＋残り60分相当3,000円の30％＝900円、合計2,400円です。これは通常の直前取消しの100％を適用する例ではありません。塾側・サービス全体の障害の場合は、未実施時間の料金は0円です。例えば最初の20分は指導でき、その後10分の障害対応を経て中止した場合、実施20分の1,000円のみを計算します。

## 別表3 免除の対象事情（第17条）
