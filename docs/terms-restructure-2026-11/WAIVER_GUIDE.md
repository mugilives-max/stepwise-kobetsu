# キャンセル料金の免除申請のご案内

**ステップワイズ個別指導**

無料取消し期限を過ぎた取消し・欠席・遅刻には、原則としてキャンセル料金が発生します。やむを得ない事情がある場合の免除申請は、以下の共通の手順で受け付けます。免除は、事情を確認したうえで個別に判断します。

## 1. お休み・遅刻の連絡を先にお願いします

受講できない、または遅れることが分かった時点で、できるだけ早くご連絡ください。遅刻の場合は、分かる範囲で到着見込みの時刻もお知らせください。資料がそろうまで連絡を待つ必要はありません。

取消しは、保護者ページの指定窓口、当塾との通常連絡に使用しているLINE、またはメールで受け付けます。連絡が到達した時刻で扱い、担当者が読んだ時刻を理由にキャンセル料金を上げません。

授業日前日の23時までの取消しは無料であり、免除申請は不要です。取消しと免除申請は別の手続きです。

## 2. 免除を検討する3つの条件

- やむを得ない事情により、予定していた授業の全部または一部を受講できなかったこと。
- 受講できない、または遅れることが分かった時点で、できるだけ早く塾へ連絡したこと。
- 説明や確認資料により、その事情を塾が確認できること。

例えば、1時間前には遅れると分かり、連絡できる状況だったのに開始直前まで連絡しなかった場合は、早めの連絡という条件を満たしません。実施した授業の授業料は、免除の対象に含みません。

## 3. 申請先と時期の目安

免除申請は、保護者から、当塾との通常連絡に使用しているLINEの個別のやり取り、または **mugilives@gmail.com** へお送りください。お休みの連絡と一緒に申請しても構いません。

**対象の授業日から7日以内を目安**に、免除を希望する旨と分かっている事情をご連絡ください。資料は後から提出できます。この目安を過ぎたことだけを理由に申請を受け付けなくするものではありません。入院中など、すぐに申請や資料の用意ができない場合は、連絡できるようになってからご相談ください。

救急搬送等で連絡自体ができなかった場合は、安全の確保や必要な対応を優先し、連絡できるようになった時点で、連絡できなかった事情とともにお知らせください。塾はその事情を確認し、連絡が授業開始後になったことだけで免除の対象外とはしません。

## 4. 確認する事情と資料の例

| 事情の例 | 説明・確認資料の例 |
|---|---|
| 公共交通の運休・遅延 | 利用予定の路線・時刻と、運行情報や遅延証明など |
| 親族の葬儀 | 日程と受講できなかった事情。追加確認が必要な場合は、必要な範囲を個別に案内します |
| 災害 | 発生日時・場所と、受講への影響が分かる説明や公表情報など |
| 重篤な体調不良で受診した場合 | 受講が困難だった事情と、受診日・救急搬送・入院等を確認できる資料など |

通常の体調不良は免除の対象外です。表にない事情も相談できます。

資料は確認に必要な部分だけで構いません。病名、保険証の番号、診療の詳細など、確認に不要な情報は隠してください。診断書の新規取得や、免除のためだけの受診は一律に求めません。手元の資料で何を確認できるか、先にご相談ください。

受診記録などはグループLINEや公開ページへ送らず、個別のやり取りで提出してください。資料をお願いする際は、利用目的・提出先・保存期間を案内します。免除の確認に使った受診記録などの資料は、確認が済み次第速やかに削除します。

## 5. 申請文の記入例

以下をコピーし、分かる範囲で記入して、個別のLINEまたはメールでお送りください。

- 生徒氏名：
- 対象の授業日時：
- 受講できなかった時間、または遅刻した時間：
- 事情と、受講できない・遅れると分かった時刻：
- 塾へ連絡した日時・方法（連絡できなかった場合はその事情）：
- 確認できる資料の有無・後日提出の見込み：
- キャンセル料金の免除を希望します。

資料がまだない場合も、先に申請できます。

## 6. 確認中の支払いと結果のご案内

審査中は、対象のキャンセル料金の支払いを保留します。それ以外の争いのない金額は、通常の期限内にお支払いください。塾は確認結果と理由をお知らせします。

請求する場合は、理由・金額・支払期限を改めてお知らせします。支払済みの金額を減額する場合は、原則として翌月請求へ充当します。振込を希望する場合、または翌月請求に充当できない差額がある場合は、減額が確定した月の翌月15日までに塾の手数料負担で返金します。

料金の計算や請求の可否についての説明・見直しの申出は、免除申請とは別に行えます。本案内の時期の目安や確認資料を、その申出の条件とすることはありません。
