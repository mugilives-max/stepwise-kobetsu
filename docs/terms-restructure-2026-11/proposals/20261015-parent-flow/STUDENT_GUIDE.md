# 生徒の皆さんへ：授業と連絡の案内

**未公開改稿案・第2案／2026年10月15日作成**

[受講規約](TERMS.md)のうち、普段の受講に関わることを短くまとめた案内です。詳しい条件は、保護者と塾が合意した規約・書類で確認してください。

## 授業が決まるまで

保護者と塾が、今月の科目・授業内容・回数・料金を合意します。その範囲で授業の日時を相談し、予約します。

カレンダーの「調整中」は相談中、「確認待ち」は回答の締め切りがある提案、「確定」は予約が成立した授業です。確認待ちの日時がいつ確定するかは、保護者へのお知らせで確認できます。

## お休み・遅刻の連絡

- **お休みは前日23時まで無料です。** 調整中・確認待ちの取りやめにもキャンセル料金はかかりません。
- **遅れると分かったら、すぐに到着見込みを知らせてください。** 通常は、遅刻しても授業の終了時刻は変わりません。
- 生徒本人からどの範囲まで連絡できるかは、保護者と決めた受講条件書で確認してください。その範囲で塾が受け付け、キャンセル料金が生じる連絡は保護者にも知らせます。
- 「別の日は空いていますか」という問い合わせだけでは、元の予約は取り消されません。取り消す場合は「○月○日の授業をお休みにします」と伝えてください。
- 別の日に受けたい場合は、新しく予約します。希望する日時に空きがないこともあります。

前日23時を過ぎると、予約した時間のうち授業が行われなかった分には、原則としてキャンセル料金がかかります。連絡の時刻で負担率が変わります。計算は[規約第17条](TERMS.md#article-17)、やむを得ない事情の相談は[免除申請の案内](WAIVER_GUIDE.md)を確認してください。

連絡先は、指定の保護者ページ・いつも使っているLINE、または **mugilives@gmail.com** です。ページを使えない場合も、LINE・メールで連絡できます。

## 安心して受講するために

体調が悪いときは無理をせず、早めに連絡してください。オンラインで接続が続けられない場合も、相手に伝えて相談できます。中止した時刻からの費用は、原因によって扱いが変わります（[規約第20条](TERMS.md#article-20)）。

設備を大切に使い、危険な行為や他の人が困る行為はしないでください。授業の録音・録画・撮影・公開は、許可を得てから行ってください。教材は自分の学習のために使い、許可なく販売・公開・第三者への提供をしないでください。法令上認められる利用まで制限するものではありません。

口コミ・写真・成績などを紹介に使うときは、受講とは別に確認します。掲載を希望しないことで、受講条件が不利になることはありません。
