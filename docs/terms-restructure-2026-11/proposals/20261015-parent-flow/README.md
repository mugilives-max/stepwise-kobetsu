# 受講規約の未公開改稿案・第2案

**2026年10月15日作成／未採用・未公開／レビュー用**

普段の条件を決め、今月の授業内容と料金に合意し、日時を予約して受講し、翌月に支払う。その順に読めるよう、規約と関連書類を組み直した案です。正式版r9の確定済み条件を比較元にしています。

## まず読むもの

1. [受講規約の改稿案](TERMS.md)：全体の流れと共通の約束。
2. [受講条件書のひな形](TEACHING_CONDITIONS_REGULAR.md)：ご家庭の普段の指導方法・授業時間・標準単価。
3. [受講合意書のひな形](TUITION_AGREEMENT.md)：今月の授業内容・回数・時間・1回の授業料。
4. [判断が必要な2点](OPEN_QUESTIONS.md)：予約と通知不備の関係、取消し等の回数への算入。

## 必要なときに読むもの

- [キャンセル料金の免除申請案内](WAIVER_GUIDE.md)。
- [口コミ・写真・実績等の広報利用承諾書](PUBLICITY_CONSENT.md)：受講への合意とは別の任意承諾。
- [現行各項との対応・確認内容](MAPPING.md)、[機械照合結果](CHECKS.json)。

## 第1案から組み直したところ

- 受講条件書と受講合意書を中心にし、標準単価を超える授業の理由・対象・期間・金額への承認は、受講合意書の該当する授業にまとめました。第2案には独立した特別単価合意書の様式を設けていません。
- 料金の主な用語を「標準単価」「1回の授業料」に絞りました。割引と承認済みの上限、例外に必要な事前承認は保っています。
- 規約は普段の条件、月ごとの合意、日時予約、欠席等の費用、請求・返金の順です。実施時間に応じた料金計算は、請求の直前にまとめました。
- 受講合意書は授業一覧から始め、「予定総額」を「記載した授業をすべて受講した場合の授業料」としました。版・ID・承認経路など塾の記録欄は末尾に置きました。
- 保留A・Bは本文で決めず、別資料に残しました。
