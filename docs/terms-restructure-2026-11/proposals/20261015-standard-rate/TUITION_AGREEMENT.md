**未採用・未公開の改稿案／2026年10月15日作成**

保護者・塾のどちらからも案を提示できます。合意前は「受講合意書（案）」とし、双方が合意した同じ版を控えとして残します。授業は受講条件書の共通条件に従い、標準単価を基本として行います。

1回の授業料は、対象月に合意済みの受講条件書の標準単価を基本とします。割引などにより下回る金額も合意できます。時間が異なる場合は同じ時間に換算して比較します。期間・時間・授業料が異なる授業は行を分けます。複数月分をまとめる場合も、月ごとの対象期間と合意を区別します。

## 特別単価の合意 該当する場合のみ

標準単価を超える授業がない場合、この欄への記入は不要です。ある場合は、次の欄に記入するか、同じ内容を示す別紙「特別単価合意書」を添付・参照します。対象や金額が異なる場合は、対象ごとに欄を追加します。

|---|---|

| 指導の名称・目的 | 　　　　　　　　　　　　　　　 |
| 指導の内容と範囲 | 　　　　　　　　　　　　　　　 |
| 特別単価を用いる理由・必要な準備 | 　　　　　　　　　　　　　　　 |

| 特別単価（税込） | 1回　　　　　　円 |
| 対象期間（開始日・終了日） | 　　　　年　　月　　日 ～ 　　　　年　　月　　日 |
| 特別に合意した条件 | 　　　　　　　　　　　　　　　 |
| 別紙を用いる場合の名称・版・ID／添付先 | 　　　　　　　　　　　　　　　 |

別紙に記載済みの説明をこの欄へ書き直す必要はありません。その場合も、対象となる上表の行番号と、参照する別紙の版・ID・添付先を記入します。

塾は理由・対象・期間・金額を事前に説明し、受講内容への合意に先立って、または同時に、特別単価についても保護者の明示的な承認を得ます。特別単価を上表の1回の授業料に記入し、割引する場合は割引後の金額を記入します。承認のない特別単価を用いたり、準備時間の費用を後から加算したりしません。

## 合意の範囲

合意した回数は対象期間内に実施可能な上限です。合意によって授業の事前購入、全回数の受講義務、全回数の受講保証、未実施分の繰越権が生じるものではありません。変更・追加には事前の双方の合意が必要です。

具体的な日時は日程調整カレンダー等で調整し、規約第4章に従って確定（予約）します。日時一覧を同時に承認する場合の添付資料名・版：　　　　　　　　　。

授業の実施には事前の明示的な合意が必要です。別紙の特別単価合意書だけを承認しても、月ごとの授業の実施承認にはなりません。詳細は適用する受講規約によります。本案の参照条項：[第7条](TERMS.md#article-7)、[第8条～第17条](TERMS.md#article-8)。

## 双方の合意の記録

合意した受講内容に加え、特別単価がある場合は、その理由・対象・期間・金額と承認された範囲を記録します。同じ回答で双方を承認する場合も、特別単価を含む内容への明示的な承認が分かるように残します。
