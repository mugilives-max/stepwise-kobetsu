# 標準単価と受講合意書の改稿案

**2026年10月15日作成／未採用・未公開**

受講条件書で共通条件と標準単価を決め、月ごとの受講合意書で具体的な授業を合意する構成です。準備負担による特別単価は、必要な場合だけ受講合意書内で説明・承認します。複数月で同じ説明を用いる場合などに、別紙の特別単価合意書も使えます。

## 読む順序

1. [受講規約の改稿案](TERMS.md)：全体の規定。
2. [受講条件書](TEACHING_CONDITIONS_REGULAR.md)：共通条件と標準単価の空欄様式。
3. [受講合意書](TUITION_AGREEMENT.md)：月ごとの内容・1回の授業料と、必要な場合の特別単価の合意欄。
4. [特別単価合意書](TEACHING_CONDITIONS_SPECIAL.md)：必要な場合だけ用いる別紙。
5. [旧版との対応と変更点](MAPPING.md)：移動先、整理の意味、保持する条件。

[キャンセル料金の免除申請案内](WAIVER_GUIDE.md)と[口コミ・写真・実績等の広報利用承諾書](PUBLICITY_CONSENT.md)も添付しています。免除案内は案の表示と参照先だけを変更し、広報利用承諾書は案の表示を加えています。両書類の内容・条件は現行版と同じです。

## 整理したこと

| 項目 | 改稿案 |
|---|---|
| 標準単価 | その生徒・家庭について合意する、普段の授業の1回当たりの税込料金。授業時間と組にして受講条件書に記載する。 |
| 1回の授業料 | 受講合意書で合意した、その授業の税込料金。標準単価を基本とし、割引による減額も可能。料金計算はこの金額を参照する。 |
| 特別単価 | 通常想定を大きく超える準備負担について事前に説明し、承認を得た、標準単価を超える料金。独立した「上限」と「適用単価」の二重定義を設けない。 |
| 合意する場所 | 原則は受講合意書内。共通の説明を複数月で用いる場合などは別紙でもよい。同一の回答で月ごとの内容と特別単価を承認する場合も、例外の理由・対象・期間・金額への明示的な承認を記録する。 |
| 説明の順序 | 共通条件・標準単価 → 月ごとの受講内容・承認 → 必要な場合の特別単価 → 日時の予約。 |

これは名称の置換だけではありません。例外の合意を受講合意書内に記録できるようにし、別紙を任意とする手続の整理を含みます。承認済みの標準単価を無断で超えないこと、特別単価も承認された金額を超えないこと、割引による減額ができることは維持します。特別単価の別紙を承認しても、それだけでは月ごとの実施承認になりません。

## 変えない条件と保留事項

- 準備の分配方法、通常の指導の延長や埼玉県公立高校入試・英検2級まで・数検・漢検の例、分配後も負担が通常想定を大きく超える場合に限る基準を保持します。
- 月単位・自動更新なし、対象期間・科目・回数の事前明示合意、回数は実施可能な上限、全回数の受講義務・受講保証・繰越権を生じない扱いを保持します。
- 指導形態、教材、予約・取消し、負担率、免除、請求、返金、安全、個人情報、広報利用の条件は変更しません。条番号の移動に伴う参照と単価の名称は整合させます。
- 本文の2026年11月1日は現行版から引き継いだ適用開始日の案です。本案の正式採用・適用を決定したものではありません。
- 保留A（未成立の予定と通知不備の予約の関係）・保留B（取消し・一部実施・再予約の回数算入）は今回も決めません。[従来の判断記録](https://github.com/mugilives-max/stepwise-kobetsu/blob/15bc4f88bb46217678cb511c4769c75d7a3e6bf9/docs/terms-restructure-2026-11/DECISIONS.md#whole-flow-r8)を維持します。
