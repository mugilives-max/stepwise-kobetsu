## 関連書類

| 書類 | 改稿内容 |
|---|---|
| 受講条件書 | 共通条件・標準単価・月ごとの受講合意という順序へ。標準単価は時間と税込金額をセットで示す。 |
| 受講合意書 | 通常／特別の区分欄と適用単価欄を、行番号と1回の授業料へ変更。必要時のみ使う特別単価欄を追加し、理由・対象・期間・金額への明示承認を記録する。 |
| 特別単価合意書 | 受講合意書の任意の別紙として位置付ける。対象授業を参照し、別紙だけでは各月の実施を承認しない。 |
| 免除申請案内 | 案の表示とリンク先のみ変更。手続・期限・免除条件等を維持。 |
| 広報利用承諾書 | 案の表示のみ追加。受講への合意と広報への任意承諾は引き続き別。 |

## 判断を追加していない点

- 保留A：未成立の予定と、通知に不備がある予約の「無効（取消し）」の関係。
- 保留B：全部取消し・一部実施・再予約を、合意回数の上限へどう算入するか。
- 特別単価への切替を認める準備時間の数値基準や、料金の自動加算式は追加しない。
- 現行システムの修正方法、適用版の切替、家庭への同意依頼日はこの改稿案で決定しない。
