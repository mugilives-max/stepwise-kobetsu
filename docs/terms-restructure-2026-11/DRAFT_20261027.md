### 第1条 指導の目的と契約者

<a id="article-1-item-1"></a>

1. ステップワイズ個別指導（代表者：麦倉優輔、所在地・教室所在地：埼玉県越谷市袋山1319-9、電話：080-6259-3025。以下「塾」）は、生徒の学力向上、基礎学力の定着、学習習慣の形成および目標達成を支援するために指導を行います。

<a id="article-1-item-2"></a>

2. 契約者は、受講申込書に記載する保護者その他受講契約を締結する権限を有する方です。以下「保護者」といいます。

### 第2条 受講までの流れと書類

<a id="article-2-item-1"></a>

1. 契約は本規約、個別受講条件書、双方が合意した特別単価合意書、双方が合意した受講計画合意書（ある場合）および[第4章](#chapter-4)により確定した予約日時によります。

<a id="article-2-item-2"></a>

2. 受講の条件・内容・日時は、次の順に定めます。各書類は、書面または電子記録として残します。

| 書類・手続 | 決めること |
| --- | --- |
| 個別受講条件書 | 生徒・家庭ごとの共通の指導条件と、通常の基準単価（適用単価の上限）に双方で合意します。 |
| 特別単価合意書（必要な場合のみ） | [第5条](#article-5)の準備負担により特別の基準単価を用いる場合、その理由・対象となる指導の内容・範囲・期間と単価に双方で合意します。指導方法等の共通条件には個別受講条件書を用います。 |
| 受講計画合意書（必要な場合のみ） | まとまった回数の授業を行うときに、対象期間・科目・回数・各回の時間・適用単価を前もって合意します。合意した範囲の授業は、日時の合意だけで受講できます（[第10条](#article-10)）。 |
| 日時の予約 | [第4章](#chapter-4)に従い、授業ごとに日時を確定します。受講計画合意書の範囲外の授業は、このとき授業料にも合意します（[第9条](#article-9)）。 |

<a id="article-2-item-3"></a>

3. 受講契約は授業ごとに結び、自動更新しません。授業ごとの合意と受講計画合意書は[第3章](#chapter-3)、日時の調整と予約は[第4章](#chapter-4)によります。授業料・キャンセル料金等は、月ごとに集計して翌月に請求します（[第23条](#article-23)）。

### 第3条 受講管理システムと連絡方法

<a id="article-3-item-1"></a>

1. 塾は、授業や契約に関する情報を確認・管理するため、オンラインの受講管理システムを利用します。主な画面は次のとおりです。

   - 保護者ページ：保護者が個別受講条件書・特別単価合意書・受講計画合意書の確認や承認、授業記録・請求の確認などを行う画面です。
   - 日程調整カレンダー：授業日時や学校行事・試験等の予定を確認する画面です。授業の日程は、LINE・面談・電話等のやり取りで決めることを基本とし、この画面は決まった日時の記録と確認のための補助として用います（[第4章](#chapter-4)）。

<a id="article-3-item-2"></a>

2. 受講計画合意書、予定、請求は保護者ページ等で案内し、登録された連絡先に通知します。日々の連絡はLINE等でも受け付けます。

<a id="article-3-item-3"></a>

3. 塾はシステムの利用方法を案内します。連絡先が変わった場合はお知らせください。ページを利用できないときは、指定のLINEまたはメール（mugilives@gmail.com）へご連絡ください。

## 第2章 指導内容と受講条件

### 第4条 指導形態と担当講師

<a id="article-4-item-1"></a>

1. 対象となる科目と具体的な指導内容は、生徒の学年、目標、理解状況を踏まえ、個別受講条件書で定め、授業ごとの合意または受講計画合意書で具体的にします。

<a id="article-4-item-2"></a>

2. 指導は、個別受講条件書で合意した教室指導、オンライン指導、またはその組合せで行います。

<a id="article-4-item-3"></a>

3. 教室指導は講師1名につき生徒最大2名を基本とし、最大2名の形態で実際の参加者が1名となっても、料金は変わりません。

<a id="article-4-item-4"></a>

4. 教室指導で1対1のみの授業は、当面行いません。希望がある場合は、内容と料金を別途相談し、合意したうえで行います。

<a id="article-4-item-5"></a>

5. オンライン指導は当面1対1で行い、料金は個別受講条件書で合意します。既存のオンライン1対1契約に、この改定だけを理由として新たな追加料金を適用しません。

<a id="article-4-item-6"></a>

6. 代表者または塾が指導を任せた講師が担当します。担当講師の変更は事前に通知します。

<a id="article-4-item-7"></a>

7. 生徒側で端末、通信環境、カメラ、マイク等をご準備ください。使用サービスと接続方法は事前に案内し、必要に応じて接続確認を行います。

<a id="article-5"></a>

### 第5条 基準単価と準備の負担

<a id="article-5-item-1"></a>

1. 授業には原則として「通常の基準単価」を用い、その指導に通常必要な準備を含めます。普段の指導の延長に当たる試験対策や問題解説も、通常の基準単価で扱います。代表的な例として、埼玉県公立高校入試の問題解説、英検2級までの対策、数検・漢検の対策が含まれます。

<a id="article-5-item-2"></a>

2. 準備の負担は、総時間だけでなく、次のように生徒1人・授業1回当たりで判断します。

   - 同じ準備を複数の生徒への指導に直接活用できる場合は、共通する準備時間をその生徒数に分配して考えます。
   - 継続的な学習の延長として定期テスト・模試・入試の対策を行う場合は、その準備の負担を、関連する一連の指導の回数に分配して考えます。

<a id="article-5-item-3"></a>

3. 「特別の基準単価」を用いる対象は、前項の方法で考えても、生徒1人・授業1回当たりの準備の負担が通常の基準単価で想定する範囲を大きく超える場合に限ります。例として、演習を授業時間に含めず、毎回異なる試験問題の解説のみを行い、その都度個別の準備を必要とする指導や、英検準1級以上の対策などがあります。名称や級、問題の難しさだけで判断せず、塾が個別に判断して事前にお伝えします。

<a id="article-5-item-4"></a>

4. 特別の基準単価は、第3項に当たる場合に、[第6条](#article-6)の事前説明と保護者の承認を経て例外的に用います。

<a id="article-6"></a>

### 第6条 基準単価の合意と記録

<a id="article-6-item-1"></a>

1. 個別受講条件書で合意した「通常の基準単価」と、特別単価合意書で合意した「特別の基準単価」を、共通して「基準単価」といいます。

<a id="article-6-item-2"></a>

2. 個別受講条件書には、対象生徒、指導科目、教室・オンラインの別、指導人数、授業時間と通常の基準単価（税込）、割引・追加料金、適用期間、特別に合意した条件を記載します。指導方法等の共通条件は、特別の基準単価を用いる授業にも適用します。

<a id="article-6-item-3"></a>

3. 特別単価合意書には、対象となる指導の名称・目的・内容と範囲、特別の基準単価を用いる理由と必要な準備、1回の時間と特別の基準単価（税込）、対象期間、特別に合意した条件を記載します。

<a id="article-6-item-4"></a>

4. 特別の基準単価は、塾が特別単価合意書（案）で[第3項](#article-6-item-3)の事項を具体的に提示し、保護者の承認を得た指導の範囲と期間に限って用います。承認は保護者ページ上の操作、書面、LINE・メール等で確認し、塾は承認の日時と方法を記録します。承認がない場合、特別の基準単価を適用しません。

<a id="article-6-item-5"></a>

5. 特別の基準単価を用いる場合も、授業の実施には授業ごとの合意または受講計画合意書が必要です。特別単価合意書の承認だけでは、授業の実施承認とはなりません。

<a id="article-7"></a>

### 第7条 適用単価と授業料

<a id="article-7-item-1"></a>

1. 各回に使用する「適用単価」は、受講計画合意書で合意した授業はその適用単価、それ以外の授業は基準単価とします。受講計画合意書の適用単価は、その指導に対応する対象月の承認済み基準単価を上限とします。単価は税込とし、授業時間が異なる場合は同じ時間に換算して比較します。

<a id="article-7-item-2"></a>

2. 授業料は、用いる基準単価にかかわらず適用単価に基づき計算し、準備時間を別途加算しません。実施時間が予約時間と異なる場合は、適用単価を時間に比例して計算し、1円未満を切り捨てます。塾都合の延長には追加料金を請求しません。通信障害により中止する場合は、[第21条](#article-21)の特則によります。

<a id="article-7-item-3"></a>

3. 体験・割引は金額、適用期間、回数、終了後の条件を示します。

<a id="article-8"></a>

### 第8条 教材と配布資料

<a id="article-8-item-1"></a>

1. 指導に必要な教材は、原則として塾が手配します。塾が指導上必要と判断して用意する教材の費用は授業料に含め、継続使用する教材や塾専用教材も含め、教材費を別途請求しません。

<a id="article-8-item-2"></a>

2. 保護者または生徒の強い希望により、前項の教材とは別に指定教材を用意する場合は、次のいずれかとします。

   - 保護者側で購入・用意する。
   - 塾に購入・手配を依頼し、購入にかかる実費を「教材手配代行費用」として支払う。

   塾が手配する場合は、教材名と負担額を示し、保護者の事前承諾を得てから、ご家庭に代わって購入します。生徒の希望だけで追加費用を確定しません。

<a id="article-8-item-3"></a>

3. 教材・資料は当面、配布のみとし、貸与は行いません。貸与を行う場合は、範囲・返却条件・紛失時の扱いを事前に合意します。

<a id="article-8-item-4"></a>

4. 教材を用意したことを理由に翌月以降の受講を義務付けたり、塾負担とした教材費を退会時にさかのぼって請求したりしません。

<a id="article-8-item-5"></a>

5. 教材・配布資料は生徒本人の学習のために利用し、許可なく販売・公開・第三者へ提供しないでください。法令上認められる利用まで制限する趣旨ではありません。

## 第3章 受講の合意と受講計画合意書

[第9条 授業ごとの合意](#article-9) · [第10条 受講計画合意書](#article-10) · [第11条 合意の方法と控え](#article-11) · [第12条 合意済み条件の変更](#article-12)

### 第9条 授業ごとの合意

<a id="article-9-item-1"></a>

1. 授業の実施には、保護者と塾の双方による事前の明示的な合意を必要とします。受講契約は、授業ごとに、その授業の日時・科目・時間・授業料に双方が合意したとき（[第13条](#article-13)）に成立します。

<a id="article-9-item-2"></a>

2. 受講計画合意書の範囲外の授業の授業料は、個別受講条件書の通常の基準単価（特別単価合意書の対象となる指導は特別の基準単価）を授業時間に比例させた額とします。ただし、同じ科目・種類の受講計画合意書があるときは、その適用単価によります。塾は、日時とあわせて授業料を示します。

<a id="article-9-item-3"></a>

3. 契約は自動更新しません。授業ごとの合意によって、それ以外の授業の受講義務や受講の保証が生じるものではありません。「授業方針に賛成する」などの一般的な意思表示だけでは、具体的な授業の実施承認とは扱いません。

<a id="article-10"></a>

### 第10条 受講計画合意書

<a id="article-10-item-1"></a>

1. 長期的にまとまった回数の授業を行うときは、授業ごとに授業料を確かめる手間を省くため、受講計画合意書で、対象生徒、対象期間（開始日・終了日）、科目ごとの授業内容と回数、各回の時間、適用単価（税込）および予定総額を前もって合意できます。受講計画合意書は必須ではありません。

<a id="article-10-item-2"></a>

2. 受講計画合意書に合意した範囲の授業は、授業日時の合意（[第13条](#article-13)）だけで受講契約が成立し、授業料は受講計画合意書の適用単価によります。各回に通常・特別のどちらの基準単価を用いるかを記載し、特別の基準単価を用いる場合は、特別単価合意書の対象となる指導の名称も示します。

<a id="article-10-item-3"></a>

3. 受講計画合意書の案は、保護者または塾のいずれからも提示できます。合意前は「受講計画合意書（案）」として区別します。

<a id="article-10-item-4"></a>

4. 合意した回数は、対象期間内に実施可能な授業回数の上限です。受講計画合意書に合意した時点で、授業の事前購入、全回数の受講義務、その回数分の受講の保証、未実施分の繰越権が生じるものではありません。

<a id="article-10-item-5"></a>

5. 受講計画合意書の案を読んだこと、返信しなかったことだけでは、その期間・科目・回数・適用単価で授業を行う承認にはなりません。

<a id="article-11"></a>

### 第11条 合意の方法と控え

<a id="article-11-item-1"></a>

1. 保護者ページを家族内で共有する場合は、契約者と承認権限を持つ方を確認します。承認操作の際は、その方が内容を確認してください。

<a id="article-11-item-2"></a>

2. 合意は、保護者ページでの承認、LINE・メールのやり取り、面談・電話等で行います。LINE・メール等のやり取りは、そのまま後で見返せる合意の記録として扱います。

<a id="article-11-item-3"></a>

3. LINE・メール・面談・電話等で日時に合意した場合は、塾がその日時を保護者ページに入れます。

<a id="article-11-item-4"></a>

4. 事前の合意なしに授業を行い、授業後に承認を求めることはしません。

<a id="article-11-item-5"></a>

5. 日程、料金、受講終了など重要な内容は、双方が確認できる方法で記録します。合意した授業の日時は、保護者ページで確認できます。

<a id="article-11-item-6"></a>

6. 塾は同意した版、対象となる書類、同意者、日時、方法を保護者ページに記録し、保護者はいつでも同じ内容を保護者ページで確認できます（控え）。記録の保管は[第31条第7項](#article-31-item-7)によります。

<a id="article-12"></a>

### 第12条 合意済み条件の変更

<a id="article-12-item-1"></a>

1. 指導形態・人数・時間、基準単価・適用単価その他の料金など、合意済みの条件を変更する場合は、変更内容と適用時期を示して説明し、変更前に改めて保護者の承認を得ます。新しい受講計画合意書の案の送付やカレンダーへの入力だけでは条件を変更できません。

<a id="article-12-item-2"></a>

2. 受講計画合意書の回数を超える授業、対象期間外の授業、受講計画合意書にない科目の授業は、[第9条](#article-9)により授業ごとに合意して行えます。この合意をした授業は、受講計画合意書に追加したものとして保護者ページに記録します。受講計画合意書のそれ以外の条件の変更は、変更版について事前に双方が合意した場合に限り行います。

<a id="article-12-item-3"></a>

3. 特別単価合意書の対象となる指導内容、特別の基準単価または対象期間を変える場合は、新しい特別単価合意書で改めて承認を得ます。

<a id="article-12-item-4"></a>

4. 承認のない月への遡及的な値上げは行いません。

### 第13条 授業日時の決め方と予約

<a id="article-13-item-1"></a>

1. 授業の日時は、LINE・面談・電話等で塾と保護者が相談して決めます。[第3条](#article-3)の受講管理システム（日程調整カレンダー）は、決まった日時を記録して確かめるための補助として用います。

<a id="article-13-item-2"></a>

2. 日時は、次のいずれかで決まり、予約（実施予定）になります。

   - LINE・メール・面談・電話等で塾と保護者が日時に合意したとき。塾がその日時を保護者ページに入れます。
   - 塾が保護者ページとメール等で日時を示して承認をお願いし（承認待ち）、保護者が保護者ページで「承認する」を押したとき。

<a id="article-13-item-3"></a>

3. 承認待ちの授業は予約ではありません。返事がないこと、時間が経ったことだけでは日時は決まらず、受講管理システムが締め切り等により自動で決めることもありません。

<a id="article-13-item-4"></a>

4. 前日23時を過ぎてから新しく予約する場合は、その時点から適用されるキャンセル料金（[第18条](#article-18)）も示して合意します。

<a id="article-13-item-5"></a>

5. 将来の固定曜日・時刻の枠は、別途約束しない限り保証しません。

> 下書きのメモ：旧第14条（授業日時の確定）・旧第15条（直前の予約）は第13条にまとめた。条の番号は統合が終わってから最後にふり直す。

<a id="article-16"></a>

### 第16条 取りやめ・取消しと連絡

<a id="article-16-item-1"></a>

1. 承認待ちの授業は予約ではないため、取りやめてもキャンセル料金はかかりません。

<a id="article-16-item-2"></a>

2. 「実施予定」は予約が成立したことを示すものであり、それだけでキャンセル料金が発生するものではありません。保護者は、授業日の前日23時まで、予約した授業を無料でお休み（取消し）にできます。行わない授業の授業料もキャンセル料金もかかりません。塾の承諾がなくても、キャンセルは成立します。

<a id="article-16-item-3"></a>

3. お休みの連絡が指定のページ・LINE等の窓口に到達した時点で、元の予約の取消しが成立します。担当者による確認や記録が後になった場合も、連絡が到達した時刻にさかのぼって処理し、その時刻をもとにキャンセル料金を計算します。

<a id="article-16-item-4"></a>

4. お休みの意思を明示しない連絡（別の日時が空いているかの問い合わせなど）は、予約の取消しとして扱いません。元の予約を取り消して別の日時で授業を希望する場合は、元の予約を取り消す旨を必ずお伝えください。

<a id="article-16-item-5"></a>

5. 生徒本人からの欠席・遅刻等の連絡は、保護者が認めた範囲（前日23時までの無料のお休みなど）で受け付けます。受け付けるかどうかは保護者が保護者ページで設定し、キャンセル料金が生じる連絡は保護者にもお知らせします。

<a id="article-17"></a>

### 第17条 別の日時への予約

<a id="article-17-item-1"></a>

1. 予約済みの授業を取り消して、別の日または別の時刻に授業を希望する場合は、元の授業とは独立した新しい予約として、[第4章](#chapter-4)に従って申し込むことができます。

<a id="article-17-item-2"></a>

2. 予約を取り消した場合、取り消した分の授業を別の日時で実施することは保証しません。講師や教室の空きがないときは、新しい予約をお受けできないことがあります。

<a id="article-17-item-3"></a>

3. 元の予約のお休みは[第16条](#article-16)により受け付けます。同日の別時刻に授業を希望する場合は、終了時刻、担当講師、他の授業を確認し、新しい予約について双方で合意します。

<a id="article-17-item-4"></a>

4. 新しい予約が成立しなかった場合でも、明示的に取り消した元の予約は復活しません。元の予約を残したまま日時を相談していた場合は、元の予約に遅刻・欠席した分を[第18・19条](#article-18)により扱います。

<a id="article-17-item-5"></a>

5. 前日23時を過ぎてから元の予約を取り消す場合、または予約していた日時の授業が実施されなかった場合は、原則としてキャンセル料金が発生し、[第18条](#article-18)によります。取り消した予約の代わりに別の予約をした場合であっても、元の予約の取消しについてキャンセル料金が発生します。同日の開始を遅らせる場合の未実施時間は[第19条](#article-19)によります。

## 第5章 欠席・変更・中止の費用

[第18条 キャンセル料金と負担率](#article-18) · [第19条 遅刻と同日の開始変更](#article-19) · [第20条 塾の都合による変更と休講](#article-20) · [第21条 オンライン授業の接続不良による中止](#article-21) · [第22条 やむを得ない事情による免除](#article-22)

<a id="article-18"></a>

### 第18条 キャンセル料金と負担率

<a id="article-18-item-1"></a>

1. 授業の取消しや欠席・遅刻・日時変更により、予約していた授業時間のうち実施されなかった時間にかかる費用を「キャンセル料金」とします。無料で取り消せる期限、負担率、免除、塾側の都合による例外は以下に定めます。オンライン授業が接続不良で中止になった場合は、[第16～20条・第22条](#article-16)ではなく[第21条](#article-21)で計算します。[第21条](#article-21)で計算した時間に、この章のキャンセル料金を重ねてかけることはありません。

<a id="article-18-item-2"></a>

2. 前日23時を過ぎてから、生徒側の事情で予約した授業の全部または一部が行われなかった場合、行われなかった時間（以下「未実施時間」）についてキャンセル料金がかかります。未実施時間は、元の予約時間の範囲内で数えます。

<a id="article-18-item-3"></a>

3. キャンセル料金は「未実施時間に相当する授業料×負担率」で計算し、10円未満を切り捨てます。「未実施時間に相当する授業料」とは、その予約で合意した授業料と時間をもとに、未実施時間の分を時間に比例して計算した額です。例えば、予約していた90分4,500円のうち30分が未実施となった場合、相当する授業料は1,500円です。

<a id="article-18-item-4"></a>

4. 負担率は、未実施時間に相当する授業料のうち保護者がキャンセル料金として負担する割合であり、連絡を受け付けた時刻によって、100％を上限として次のとおり定めます。

| 連絡の時刻 | 負担率 |
| --- | --- |
| 前日23時まで | 0％ |
| 前日23時を過ぎ、開始3時間前まで | 25％ |
| 開始3時間前を過ぎ、開始時刻より前 | 100％－75％×開始までの残り分数÷180 |
| 開始時刻以降、または連絡なし | 100％ |

<a id="article-18-item-5"></a>

5. 前日23時ちょうどまでを無料とし、この規定を他の時間帯区分より先に適用します。ページ・LINE・メール等の受付時刻を使い、塾が読んだ時刻や後から入力した時刻を理由に負担率を引き上げません。

<a id="article-18-item-6"></a>

6. 同じ時間に、授業料とキャンセル料金の両方をかけることはありません。明細では、実施した分の授業料とキャンセル料金を分けて示します。

<a id="article-18-item-7"></a>

7. キャンセル料金は予約ごとに計算します。別日時の新しい予約は別の予約として扱い、新しい予約を取り消した場合も、その予約について本条により計算します。複数の連絡や変更が重なる細かな場面は、事実を確認して個別にご説明します。

<a id="article-19"></a>

### 第19条 遅刻と同日の開始変更

<a id="article-19-item-1"></a>

1. 遅れることが分かったら、その時点で到着の見込みをお知らせください。連絡がない場合の負担率は100％です。

<a id="article-19-item-2"></a>

2. [第17条第3項](#article-17-item-3)で開始を変更した場合を除き、遅刻しても授業は予定の終了時刻に終わります。遅れた時間は未実施時間として[第18条](#article-18)で計算し、実際に行った時間は授業料として計算します。

<a id="article-19-item-3"></a>

3. 到着の見込みよりさらに遅れた分は、改めて連絡を受けた時刻の負担率、追加連絡がなければ100％で計算します。

<a id="article-19-item-4"></a>

4. 無料期限後の予約変更で、元の予約時間と新しい予約時間が重なる場合、元の予約時間のうち実際に指導した時間を除いた未実施時間にだけ、[第18条](#article-18)のキャンセル料金を適用します。実施分の授業料は[第7条](#article-7)によります。元の予約枠の同じ時間に授業料とキャンセル料金を重ねません。

<a id="article-19-item-5"></a>

5. 変更後の日時、元の予約の未実施時間、新しい予約の授業料と見込み合計額を示し、実施前に承諾を得ます。

<a id="article-19-item-6"></a>

6. 遅刻・当日の変更が続く場合は、無理なく通える曜日・時間について保護者と相談します。

<a id="article-20"></a>

### 第20条 塾の都合による変更と休講

<a id="article-20-item-1"></a>

1. 塾の都合で日時を変更するときは、できるだけ早く連絡し、変更後の日時を相談します。保護者・生徒にキャンセル料金はかかりません。

<a id="article-20-item-2"></a>

2. 塾の都合で行えなかった時間の授業料は請求しません。別の日に授業を行う場合は、その実施分について合意した料金を請求します。

<a id="article-20-item-3"></a>

3. 塾の都合による休講と、生徒側の都合による取消は、記録と明細を分けます。

<a id="article-21"></a>

### 第21条 オンライン授業の接続不良による中止

<a id="article-21-item-1"></a>

1. 接続不良によって授業の継続が困難な場合は、授業を中止できます。中止する旨を相手方へ知らせ、中止時刻を記録します。接続手段が使えない場合は、LINEまたはメール等で連絡します。

<a id="article-21-item-2"></a>

2. 生徒側の通信環境・端末等の不具合で中止する場合は、次のとおり計算します。

| 時間の区分 | 料金の扱い |
| --- | --- |
| 予定開始時刻から中止時刻まで | 通常の授業料で計算します。接続の確認・復旧に費やした時間を含みます。 |
| 中止時刻から予定終了時刻まで | その時間に相当する授業料の30％をキャンセル料金として計算します。 |

   中止後は授業のために待機し続ける必要はありません。

<a id="article-21-item-3"></a>

3. 塾側の不具合、または利用サービス全体の障害によって実施できなかった時間には、授業料もキャンセル料金も請求しません。中止前であっても、障害により実施できなかった時間を通常料金へ含めません。実際に実施した分だけを計算します。

<a id="article-21-item-4"></a>

4. 第2項の通常料金部分は1円未満、30％部分は10円未満を切り捨てます。同じ時間に[第18条](#article-18)の通常キャンセル料金や他の授業料を重ねません。後日行う授業は別の予約として合意します。

<a id="article-21-item-5"></a>

5. 開始前の中止、短時間の切断、原因が分からない場合は、原因不明のまま生徒側の不具合と扱わず、事実を確認して個別にご説明します。

<a id="article-22"></a>

### 第22条 やむを得ない事情による免除

<a id="article-22-item-1"></a>

1. 無料取消し期限を過ぎた取消しや欠席・遅刻には、原則としてキャンセル料金が発生します。ただし、次の3条件をすべて満たす場合は、申請により個別に免除することがあります。

   - (1) やむを得ない事情により、予定していた授業の全部または一部を受講できなかったこと。
   - (2) 受講できない、または遅れることが分かった時点で、できるだけ早く塾へ連絡したこと。
   - (3) 説明や確認資料により、その事情を塾が確認できること。

   実施分の授業料は免除対象に含みません。

<a id="article-22-item-2"></a>

2. 例えば、授業の1時間前には到着が遅れると分かっており、連絡できる状況だったにもかかわらず、開始直前まで連絡しなかった場合は、第1項の(2)を満たしません。救急搬送等で連絡自体ができない場合は、第3項の扱いによります。

<a id="article-22-item-3"></a>

3. 対象となる事情の例は、公共交通の運休・遅延、親族の葬儀、災害、重篤な体調不良で受診した場合などです。通常の体調不良は対象外です。申請窓口・時期の目安・確認資料・救急搬送等で連絡自体ができない場合の扱いは、[キャンセル料金の免除申請のご案内](https://www.stepwise-education.jp/terms/2026-11-20261027-r15/waiver/)で共通に示し、個別の事情を確認します。

<a id="article-22-item-4"></a>

4. 資料は確認に必要な範囲に限り、病名等の不要な情報は隠してください。取得目的、提出窓口、保存期間は事前に案内します。

<a id="article-22-item-5"></a>

5. 塾は確認結果と理由を回答します。保留・訂正・返金は[第24・25条](#article-24)によります。例にない事情も相談できます。料金への異議申出は[第24条](#article-24)に従い、免除の申請とは分けます。

## 第6章 請求・支払い・返金

[第23条 請求と支払い](#article-23) · [第24条 キャンセル料金の確認・見直しと支払い](#article-24) · [第25条 請求の訂正と返金](#article-25)

<a id="article-23"></a>

### 第23条 請求と支払い

<a id="article-23-item-1"></a>

1. 当月に実施した授業の料金、キャンセル料金、および[第8条第2項](#article-8-item-2)により事前合意した教材手配代行費用を集計します。家族で合算する場合も、生徒別の内訳を示します。

<a id="article-23-item-2"></a>

2. 原則として翌月3日に請求を確定し、保護者ページでお知らせします。1日と2日は塾が内容を確認する期間です。

<a id="article-23-item-3"></a>

3. 支払期限は請求が確定した月の15日です。15日が土日祝日の場合は翌営業日です。

<a id="article-23-item-4"></a>

4. 授業料等は、原則として銀行振込でお支払いください。特別な事情により銀行振込が難しい場合は、事前にご相談ください。塾が個別に承認した場合は、別途合意した方法でお支払いいただけます。

<a id="article-23-item-5"></a>

5. 銀行振込の手数料は、振込を行う保護者が負担します。

<a id="article-23-item-6"></a>

6. 支払期限までの支払いが難しい場合は、事前にご相談ください。連絡なく未払いが続く場合は、連絡・確認のうえ、授業の一時停止などを検討します。

<a id="article-24"></a>

### 第24条 キャンセル料金の確認・見直しと支払い

<a id="article-24-item-1"></a>

1. 保護者は、キャンセル料金の計算や料金がかかる条件、法令上請求できるかどうかに疑問がある場合、対象の授業と疑問の内容を示し、保護者ページまたは指定のLINE等から説明・見直しを申し出ることができます。法令名を調べたり、専門家の意見書を用意したりする必要はありません。

<a id="article-24-item-2"></a>

2. キャンセル料金の免除申請の審査中、または第1項の申出について塾が確認・回答するまでの間は、対象のキャンセル料金の支払いを保留します。それ以外の争いのない金額は、通常の期限内にお支払いいただきます。

<a id="article-24-item-3"></a>

3. 塾は第1項の申出を受け付け、事実関係と料金の計算根拠を確認します。受付から7日以内を目安に、確認結果と理由を、保護者ページ・LINE・メール等の後で見返せる方法で回答します。

<a id="article-24-item-4"></a>

4. 請求に誤りがある場合、または法令上請求できない部分がある場合は、その部分を訂正・除外します。それ以外の場合も、個別の事情を考慮し、キャンセル料金の全部または一部を減額・免除することがあります。

<a id="article-24-item-5"></a>

5. 塾が確認の結果、キャンセル料金の全部または一部を請求すると判断した場合は、請求する理由、金額と支払期限を改めてお知らせします。

<a id="article-24-item-6"></a>

6. 回答後に請求する金額は、次の請求（翌月15日期限）にまとめます。支払済みの場合は[第25条第1項](#article-25-item-1)に従って精算します。

<a id="article-24-item-7"></a>

7. 塾が請求すると回答した場合でも、法令上無効な部分は支払う必要がありません。これには塾の了承を必要としません。

<a id="article-24-item-8"></a>

8. 保護者は、塾への申出や回答の有無にかかわらず、消費生活センター等への相談や裁判などの紛争解決手続を利用できます。本条の手続によって、これらを含む保護者の法令上の権利を制限しません。

<a id="article-25"></a>

### 第25条 請求の訂正と返金

<a id="article-25-item-1"></a>

1. 確定後の訂正は、元の請求と訂正理由を残して通知します。支払済みの請求額が減額された場合は、払い過ぎた差額を、原則として翌月の請求への充当で精算します。

<a id="article-25-item-2"></a>

2. 保護者が振込を希望する場合、または翌月の請求がない・請求額を上回るなどの理由で翌月の請求に充当できない差額がある場合は、その返金額を減額が確定した月の翌月15日までに振り込みます。

<a id="article-25-item-3"></a>

3. 塾から返金する場合の振込手数料は、塾が負担します。

## 第7章 契約の終了と規約変更

[第26条 受講の終了と最終精算](#article-26) · [第27条 契約違反による受講停止と解除](#article-27) · [第28条 規約の版と変更への同意](#article-28)

<a id="article-26"></a>

### 第26条 受講の終了と最終精算

<a id="article-26-item-1"></a>

1. 保護者は、ページ・LINE・メール等で受講終了を申し出ることができます。新しい授業について双方が合意しない限り、新しい受講契約は成立しません。

<a id="article-26-item-2"></a>

2. 終了の申出があっても、保護者が希望する場合は、既に実施承認・予約されている授業を受講できます。塾は、受講を希望する予約と取り消す予約、最終受講日を確認します。

<a id="article-26-item-3"></a>

3. 塾が翌月以降の継続を行えない場合は、原則1か月前までに連絡します。急病・事故等は分かり次第連絡します。

<a id="article-26-item-4"></a>

4. 精算するのは、実施した授業の授業料、取り消した予約にキャンセルポリシーが適用される場合のキャンセル料金、および[第8条第2項](#article-8-item-2)により事前合意した教材手配代行費用です。これら以外の解約金・退会金等は一切請求しません。

<a id="article-26-item-5"></a>

5. 取り消す予約は[第16～20条・第22条](#article-16)に従います。前日23時までに取消しを受け付けた予約に、終了の申出を理由として新たな料金を加算しません。

<a id="article-26-item-6"></a>

6. 対象期間の途中で特別単価合意書の対象となる指導をやめる場合、その指導の授業料は実施した分だけを精算し、残期間の授業料や終了自体に対する解約金は請求しません。予約済みの授業を取り消す場合は、第4・5項に従い、通常の基準単価を用いる場合と同じキャンセルポリシーを適用します。

<a id="article-27"></a>

### 第27条 契約違反による受講停止と解除

<a id="article-27-item-1"></a>

1. 契約違反がある場合は、相当な期間を定めて是正を求め、改善されないときに契約を解除できます。

<a id="article-27-item-2"></a>

2. 暴力など安全や信頼関係に重大な支障を与える場合は、直ちに受講を停止し、契約を解除することがあります。具体的な適用は事情に応じて判断します。

<a id="article-27-item-3"></a>

3. 終了時の料金は[第26条](#article-26)に従い精算します。

<a id="article-28"></a>

### 第28条 規約の版と変更への同意

<a id="article-28-item-1"></a>

1. 適用する規約は、保護者が同意した版の全文です。掲載ページを更新したことだけで、過去に同意した内容を置き換えません。

<a id="article-28-item-2"></a>

2. 条件を変更する場合は、変更点と適用時期を保護者ページ等で示し、同意を得た契約から適用します。

<a id="article-28-item-3"></a>

3. 同意しない場合、変更後の条件による契約は成立しません。受講継続の可否や終了日を確認し、既に成立している契約と精算は従前の合意に従います。

<a id="article-28-item-4"></a>

4. この版は（適用日：公開するときに決める）から適用します。ただし、同日より前に新たに入塾する場合は、入塾の申込みの日から適用します。適用日より前に成立したその他の契約と精算は、従前の合意によります。

## 第8章 安全・情報・相談

[第29条 教室利用・安全と禁止事項](#article-29) · [第30条 保護者ページの管理](#article-30) · [第31条 個人情報と録音の取り扱い](#article-31) · [第32条 実績や口コミの広報利用](#article-32) · [第33条 協議と法令上の権利](#article-33)

<a id="article-29"></a>

### 第29条 教室利用・安全と禁止事項

<a id="article-29-item-1"></a>

1. 塾は生徒の安全確保に努めます。生徒は設備・備品を適切に使用し、危険な行為をしないでください。

<a id="article-29-item-2"></a>

2. 体調不良時は無理に受講せず、早めにご連絡ください。緊急時の連絡先を塾にお知らせください。

<a id="article-29-item-3"></a>

3. 故意または重大な過失による設備等の破損・紛失については、事情を確認して相当額の負担を求めることがあります。

<a id="article-29-item-4"></a>

4. 暴力、暴言、威圧、著しい迷惑行為、許可のない授業の録音・録画・撮影・配信・公開、教材の不正利用など、指導や他者の権利を侵害する行為は禁止します。

<a id="article-29-item-5"></a>

5. 事故等の責任は原因と法令に基づき判断し、本規約によって塾の法令上の責任を一律に免除するものではありません。

<a id="article-30"></a>

### 第30条 保護者ページの管理

<a id="article-30-item-1"></a>

1. 保護者はパスワードと生徒の専用リンクを適切に管理し、契約・受講に関係のない第三者へ共有しないでください。不正利用が疑われる場合は速やかに塾へご連絡ください。

<a id="article-30-item-2"></a>

2. 設定・再設定の方法はページ等で案内します。利用できない場合の連絡手段は[第3条](#article-3)によります。

<a id="article-30-item-3"></a>

3. アカウント共有等があったことだけを理由に、塾の責任を一律に免除するものではありません。

<a id="article-31"></a>

### 第31条 個人情報と録音の取り扱い

<a id="article-31-item-1"></a>

1. 氏名・学年・学校・連絡先、成績、授業・宿題の記録、契約・請求・入金の記録、および第4項の録音を、次の目的に利用します。

   - 指導・学習支援、指導計画の提案・見直し
   - 次回面談の準備、連絡
   - 契約・請求の管理

<a id="article-31-item-2"></a>

2. 管理にはCloudflare（台帳・ファイルの保管）およびGoogle（メール・カレンダー）の外部サービスを利用します。

<a id="article-31-item-3"></a>

3. 講師には指導に必要な担当生徒の情報を共有し、料金・請求や免除申請の受診資料を、指導に不要な講師へ見せない運用とします。

<a id="article-31-item-4"></a>

4. 面談等の録音は当面行いません。行う場合は、聞き違いや記録漏れを防ぎ、ご家庭の希望・課題や面談で決めたことを次の指導計画・相談に正確に引き継ぐために利用します。目的・保存・閲覧の範囲を事前に説明し、同意を得てから行います。

<a id="article-31-item-5"></a>

5. 法令に基づく場合や適法な業務委託等を除き、同意なく個人情報を第三者に提供しません。必要な安全管理を行い、保存期間を定めます。

<a id="article-31-item-6"></a>

6. 記録に誤りがある場合は訂正を申し出ることができます。

<a id="article-31-item-7"></a>

7. 契約終了後の契約・請求・同意記録等は、精算への対応および税務関係法令に基づく保存のため、記録の種類に応じて必要な期間（最長7年）保管します。

<a id="article-31-item-8"></a>

8. 免除の確認に使った受診記録などの資料は、確認が済み次第速やかに削除します。

<a id="article-32"></a>

### 第32条 実績や口コミの広報利用

<a id="article-32-item-1"></a>

1. 成績推移、写真、体験談、口コミ等を広報に使う場合は、別途「口コミ・写真・実績等の広報利用承諾書」で利用内容、掲載先、表示する情報、期間等を具体的に定め、受講の同意とは別に同意を得ます。

<a id="article-32-item-2"></a>

2. 匿名でも個人が推測できる場合があります。同意しないことによって受講条件を不利に変更しません。

<a id="article-32-item-3"></a>

3. 利用停止は指定窓口に申し出ることができます。

<a id="article-33"></a>

### 第33条 協議と法令上の権利

<a id="article-33-item-1"></a>

1. 本規約に定めのない事項や疑義は、双方が誠実に協議します。本規約は、法令により認められる取消し、解除、損害賠償請求その他の権利を妨げるものではありません。

## 別表1 キャンセル料金と合計料金の例

90分・4,500円、18時開始・19時30分終了の授業の例です。実施分の授業料は1円未満、キャンセル料金は10円未満を切り捨てます。

| 全部を取り消す連絡の時刻 | 負担率 | 授業料 | キャンセル料金 | 合計 |
| --- | --- | --- | --- | --- |
| 前日23時まで | 0％ | 0円 | 0円 | 0円 |
| 前日23時を過ぎ当日15時まで | 25％ | 0円 | 1,120円 | 1,120円 |
| 当日16時 | 50％ | 0円 | 2,250円 | 2,250円 |
| 当日17時 | 75％ | 0円 | 3,370円 | 3,370円 |
| 当日17時30分 | 87.5％ | 0円 | 3,930円 | 3,930円 |
| 当日18時以降または連絡なし | 100％ | 0円 | 4,500円 | 4,500円 |

| 実施した場合の例 | 授業料 | キャンセル料金 | 合計 |
| --- | --- | --- | --- |
| 17時に30分遅らせる連絡、塾が承諾し18時30分から90分実施 | 4,500円 | 1,120円 | 5,620円 |
| 17時30分に30分遅刻を連絡、18時30分から19時30分まで実施 | 3,000円 | 1,310円 | 4,310円 |

## 別表2 接続不良による中止の計算例（第21条）

**生徒側の接続不良の例**

生徒側の接続不良により90分4,500円の授業を開始30分後に中止した場合、開始から中止まで1,500円＋残り60分相当3,000円の30％＝900円、合計2,400円です。これは通常の直前取消しの100％を適用する例ではありません。

**塾側・サービス全体の障害の例**

塾側・サービス全体の障害の場合は、未実施時間の料金は0円です。例えば最初の20分は指導でき、その後10分の障害対応を経て中止した場合、実施20分の1,000円のみを計算します。
