### 承諾書の使い方

1. 公開リポジトリには空欄の様式だけを置く。記入済み書類、署名、本人確認用の氏名、限定公開の素材リンク、承諾のやり取りはGitHubに保存しない。
2. 塾が掲載する最終版を添え、素材番号・表示情報・掲載先・期間を記入する。同じ口コミをホームページとSNSに載せる場合は、掲載欄を分ける。空欄の掲載先や将来の素材に承諾を広げない。
3. 対象者に完成した書類全体と添付資料を渡し、掲載欄ごとの可否を確認する。未成年の生徒に関する素材は親権者等の承諾と本人の意向を確認する。成年の生徒の情報は本人、保護者が書いた口コミはその保護者から承諾を得る。複数の人の情報や作品が含まれる場合は、それぞれの対象と権限を確認する。
4. 紙への記入、または書類番号・版・対象の掲載番号・承諾の意思・回答者が分かるLINEやメールの返信を保存する。既読・無回答は承諾にしない。塾の確認記録と同じ版の控えを本人へ渡してから掲載する。
5. 掲載後は期間終了・停止申出・変更の有無を確認し、掲載先ごとの停止状況を記録する。承諾を得た後で本文や写真を差し替える場合も、変更後の仕上がりを示して改めて承諾を得る。
