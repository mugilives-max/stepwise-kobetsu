## 編集方針

1. 基本指導条件書と特殊指導条件書を並列に置く。役割の全体像を先に示し、指導の区分・記載事項・料金を続ける。
2. 契約期間、計画の承認方法、実施可能な範囲を分ける。日時決定における無回答の扱いを、計画自体の明示承認へ広げない。
3. 欠席・変更・塾都合と通信中止を近くに配置し、通常キャンセルと通信特則の適用区分を保つ。
4. 通常の請求・支払いと、申出→保留→回答→訂正・精算を分ける。
5. 初回は原文の各文を基本として移動・分割した。その後、本人から指定された分かりづらい箇所を修正し、変更前後と理由を対応表に記録する。未指示の権利・義務の補完はしない。意味が重複する記載事項と単価上限だけ2か所を集約し、対応表に前後を示す。
6. 3つの判断待ち箇所は文言を保持する。読み方を決める但書、免除や課金の例外、自動充当の規定を加えない。

### 承諾書の使い方

1. 公開リポジトリには空欄の様式だけを置く。記入済み書類、署名、本人確認用の氏名、限定公開の素材リンク、承諾のやり取りはGitHubに保存しない。
2. 塾が掲載する最終版を添え、素材番号・表示情報・掲載先・期間を記入する。同じ口コミをホームページとSNSに載せる場合は、掲載欄を分ける。空欄の掲載先や将来の素材に承諾を広げない。
3. 対象者に完成した書類全体と添付資料を渡し、掲載欄ごとの可否を確認する。未成年の生徒に関する素材は親権者等の承諾と本人の意向を確認する。成年の生徒の情報は本人、保護者が書いた口コミはその保護者から承諾を得る。複数の人の情報や作品が含まれる場合は、それぞれの対象と権限を確認する。
4. 紙への記入、または書類番号・版・対象の掲載番号・承諾の意思・回答者が分かるLINEやメールの返信を保存する。既読・無回答は承諾にしない。塾の確認記録と同じ版の控えを本人へ渡してから掲載する。
5. 掲載後は期間終了・停止申出・変更の有無を確認し、掲載先ごとの停止状況を記録する。承諾を得た後で本文や写真を差し替える場合も、変更後の仕上がりを示して改めて承諾を得る。

### 様式作成時の確認資料

現行規約の別途同意・不同意による不利益なし・利用停止申出という方針を起点にした。同意の対象を具体的に示して意思表示を確認すること、本人が判断できない場合の法定代理人等の扱いは、個人情報保護委員会の[通則編「本人の同意」](https://www.ppc.go.jp/personalinfo/legal/guidelines_tsusoku/)および[子どもの同意に関するQ&A](https://www.ppc.go.jp/all_faq_index/faq1-q1-62/)を参照（2026-10-12確認）。未成年者の本人意向確認、最終版の提示、掲載終了の手順は、この様式での運用として具体化したもので、すべてを法定の一律要件と説明するものではない。

### 保存・利用目的の説明の根拠

[国税庁「青色申告制度」](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2070.htm)では、帳簿・書類は原則7年、書類により5年と説明されている。すべての契約・同意記録が一律に法定7年保存であるとは記載しない。実際の税務書類の分類と保存の起算日は、該当する法令・手引きに沿って管理する。今回、既存の最長7年という規約上の期間を一律に延長する変更はしていない。

利用目的は、家庭がどのように情報を使うか分かる程度に具体化するという[個人情報保護委員会の説明](https://www.ppc.go.jp/all_faq_index/faq1-q2-1/)に沿い、計画提案や面談準備を明記した。確認日は2026-10-12。
