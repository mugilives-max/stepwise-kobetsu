# 受講合意書の印刷・PDF保存の見本

2026-10-16、[PR #79](https://github.com/mugilives-max/stepwise-kobetsu/pull/79)の確認用。すべて架空の生徒・承認記録です。正式規約の差し替えや本番公開をするものではありません。

- [書類のひな形に表示する見本](sample.pdf)：通常指導1科目、規約の参照と承認記録を記載。
- [承認前の案](proposal.pdf)：2科目の提案。画面で変更途中の回数は含めません。
- [承認後の控え](approved.pdf)：承認した回数で計算。提案時の内訳との違いも示します。
- [長い内容と過去の記録の例](long-history.pdf)：複数ページに続く内容と、当時の記録がない項目の表示を確認します。

案・承認後・長文の例では、条件書や規約版を未登録とした架空データを使っています。「記録なし」を現在の情報で推測して埋めないことの検証です。実際に保存された条件書のID・規約版は書面へ表示します。

## システムでの開き方

- 管理側：受講合意書 → 受講合意書全体を見る → 印刷・PDF保存。過去の版は「過去の版・控えを開く」。
- 保護者側：お支払い → 受講合意書の案・控え → 印刷・PDF保存。過去分は「過去の契約・同意の控え」。
- 書面を開いたら「印刷・PDF保存」を押し、印刷画面で「PDFに保存」とA4を選びます。
- 書面を開く操作は、承認・通知・請求の確定を行いません。

PDFファイルをサーバーへ自動保管する機能ではなく、保存済みの合意の各版から書面を開いてPDF保存する機能です。内容を変えた後でも、履歴から当時の版を出力できます。異なる生徒・期間・承認状態は別の書面に分けます。
