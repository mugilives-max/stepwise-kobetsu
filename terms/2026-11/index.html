第1条 指導の目的と内容

  1. ステップワイズ個別指導（代表者：麦倉優輔、所在地・教室所在地：埼玉県越谷市袋山1319-9、電話：080-6259-3025。以下「塾」）は、生徒の学力向上、基礎学力の定着、学習習慣の形成および目標達成を支援するために指導を行います。
  2. 対象となる科目と具体的な指導内容は、生徒の学年、目標、理解状況を踏まえ、個別指導条件書および指導計画承認書で定めます。
  3. 塾は誠実に指導しますが、成績向上、合格、資格取得その他一定の成果を保証するものではありません。
  4. 生徒と保護者は、無理のない範囲で、宿題・復習などの家庭学習に協力するものとします。

第2条 契約者と契約を構成する書類

  1. 契約者は、受講申込書に記載する保護者その他受講契約を締結する権限を有する方です。以下「保護者」といいます。
  2. 個別指導条件書は、家庭ごとの継続的な指導条件を記録し、双方で合意する書面または電子記録です。対象生徒、指導科目、教室・オンラインの別、指導人数、通常指導（第5条）の基本の授業時間と税込基本単価、割引・追加料金、適用期間、特別に合意した条件を記載します。
  3. 特殊指導承認書は、生徒ごとに、通常指導とは別に料金を定めて行う特殊指導（第5条）の内容と料金を記録し、双方で合意する書面または電子記録です。特殊指導の名称、指導の内容と範囲、通常指導との違い、必要な準備、1回の時間と税込料金、対象期間、特別に合意した条件を記載します。個別指導条件書が通常指導の単価の根拠となるのと同じように、特殊指導承認書が特殊指導の単価の根拠となります。
  4. 指導計画承認書は、保護者または塾が案を提示し、双方が合意した指導の実施範囲を記録する書面または電子記録です。対象生徒、対象月と実施可能期間（開始日・終了日）、科目別の授業内容・回数・各回の時間・単価・予定総額を記載し、各回が通常指導か特殊指導（その名称）かを示します。授業日時は第7条の日程調整カレンダーで予約します。日時一覧を指導計画承認書に添えて同時に承認することもできます。
  5. 契約は本規約、個別指導条件書、双方が合意した特殊指導承認書、双方が合意した指導計画承認書および合意した予約日時によります。基本単価や指導人数など合意済みの条件を変更する場合は、変更箇所と適用時期を示して改めて保護者の承認を得ます。新しい計画の送付やカレンダーへの入力だけでは条件を変更できません。

第3条 指導形態と担当講師

  1. 指導は、個別指導条件書で合意した教室指導、オンライン指導、またはその組合せで行います。
  2. 教室指導は講師1名につき生徒最大2名を基本とし、最大2名の形態で実際の参加者が1名となっても、料金は変わりません。
  3. 教室指導で1対1のみの授業は、当面行いません。希望がある場合は、内容と料金を別途相談し、合意したうえで行います。
  4. オンライン指導は当面1対1で行い、料金は個別指導条件書で合意します。既存のオンライン1対1契約に、この改定だけを理由として新たな追加料金を適用しません。
  5. 代表者または塾が指導を任せた講師が担当します。担当講師の変更は事前に通知します。指導形態・人数・時間・料金の変更には、説明して保護者の承認を得ます。

第4条 指導計画承認書の提案・合意と実施範囲

  1. 指導計画承認書の案は、保護者または塾のいずれからも提示できます。授業の実施には、保護者と塾の双方による事前の明示的な合意を必要とします。塾は、合意した指導計画承認書に定める期間内に、その科目と回数の範囲に限って授業を実施できます。「授業方針に賛成する」などの一般的な意思表示だけでは、具体的な授業の実施承認とは扱いません。
  2. 合意は、保護者ページ上の操作、LINE・メールのやり取り、面談・電話等で確認します。案には対象生徒、対象月・開始日・終了日、科目ごとの具体的な内容と回数、各回の時間、税込単価および予定総額を示します。塾は提案者、双方が合意した同一の版、双方の意思表示とその日時・経路を記録します。合意前は「指導計画承認書（案）」として区別します。
  3. 面談・電話の場合も、授業実施まで時間がない場合を除き、できる限り実施前にページ・LINE・メール等で承認のやり取りを残します。時間がない場合も口頭での明示的な承認は必要であり、塾が具体的な内容と日時を記録し、速やかに控えを送ります。記録が後になることと、承認自体を授業後に得ることは区別します。
  4. 面談等の録音は当面行いません。行う場合は、目的・保存・閲覧の範囲を事前に説明し、同意を得てから行います。
  5. 受講契約は暦の月ごとに結びます。初月が月途中の場合は合意した開始日から月末までです。対象月の開始前でも、その対象月の指導計画承認書に双方が合意すれば、その月の受講契約が成立します。
  6. 塾から提案する場合は、原則として前月20日ごろまでに翌月の案を提示します。保護者からの提案も受け付けます。指導計画承認書の単価は、第6条に定める根拠（個別指導条件書の基本単価、または特殊指導承認書の料金）を上限とします。
  7. 契約は自動更新しません。翌月分について双方の合意がなければ翌月の受講契約は成立しません。複数月の学習計画はまとめて作れますが、月ごとの実施可能期間と合意を区別します。先の学習方針への同意だけで将来月の指導計画承認書が成立するものではありません。
  8. 合意した回数は実施できる範囲を定めるもので、固定回数の購入、固定月謝、全回数の受講義務や未実施分の繰越権を意味しません。期間外の実施、回数の追加、科目の追加・変更その他の条件変更は、変更版または追加の指導計画承認書について事前に双方が合意した場合に限り行います。

第5条 指導の区分（通常指導と特殊指導）

  1. 指導は「通常指導」と「特殊指導」に分けます。通常指導は、個別指導条件書で合意した基本の授業時間と税込基本単価で行う指導です。特殊指導は、次の(i)(ii)の両方に当たる指導、またはいずれかの程度が大きい指導をいい、通常指導とは別に料金（特殊指導料金）を定めます。
    • (i) その生徒のために、個別に長時間の授業準備が必要であること
    • (ii) その準備を、他の生徒の指導に活用することが難しいこと
  2. 特殊指導に当たり得る例は、演習を授業時間に含めず毎回の試験問題の解説のみを行う指導（講師が事前に問題を解く等の準備が必要なもの）、英検準1級以上の対策などです。通常指導の延長に当たる内容は特殊指導にせず、埼玉県公立高校入試の問題解説、英検2級までの対策、数検・漢検の対策は通常指導に含めます。名称や級だけで判断せず、塾が個別に判断して事前にお伝えします。
  3. 特殊指導は、塾が特殊指導承認書（案）で名称、指導の内容と範囲、通常指導との違い、必要な準備、1回の時間と税込料金、対象期間を具体的に提示し、保護者の承認を得た範囲と期間でだけ行います。承認は保護者ページ上の操作、書面、LINE・メール等で確認し、塾は承認の日時と方法を記録します。承認がない場合、特殊指導として扱わず、特殊指導料金を適用しません。
  4. 特殊指導の月ごとの回数は、通常指導と同じく指導計画承認書で合意します。特殊指導承認書の承認だけでは、授業の実施承認とはなりません。
  5. 対象期間の途中で特殊指導をやめる場合は、実施した分だけを精算します。内容、料金または期間を変える場合は、新しい特殊指導承認書で改めて承認を得ます。
  6. 特殊指導のための準備が、他の生徒の通常指導にもつながる場合は、その準備を理由として基本単価を上回る料金を請求しません。

第6条 料金

  1. 授業の単価の根拠は、通常指導については個別指導条件書で合意した基本単価、特殊指導については特殊指導承認書で合意した料金です。指導計画承認書の単価は、対象月について承認済みのそれぞれの根拠を上限とします。授業時間が根拠の時間と異なる場合は、その時間に換算して比較します。
  2. 料金の計算は、通常指導と特殊指導で同じ仕組みによります。実施時間が予約時間と異なる場合は、合意単価を時間に比例して計算し、1円未満を切り捨てます。塾都合の延長には追加料金を請求しません。通信障害により中止する場合は、第17条の特則によります。
  3. 体験・割引は金額、適用期間、回数、終了後の条件を示します。基本単価、特殊指導料金その他の料金を変更する場合も、変更内容と適用時期について事前承認を得ます。承認のない月への遡及的な値上げは行いません。
  4. 教材の費用は第16条によります。

第7条 日程調整カレンダーによる日時の決定と予約

  1. 日程調整カレンダーは、指導計画承認書で実施承認された授業について、具体的な実施日時を調整し、決定・予約するためのシステムです。学校行事・試験等の予定も、日程調整の参考として登録できます。
  2. 双方が合意した指導計画承認書の期間・科目・回数・時間の範囲で日時を合意し、予約を記録します。カレンダー操作だけで、合意した期間・科目・回数の範囲を広げたり、単価を上げたりしません。日時一覧を計画とともに承認した場合は、その日時を予約として記録できます。
  3. 承認済みの指導計画承認書の範囲で塾が日時を提案する場合、塾は保護者ページ・LINE等で、日時と回答の締め切りを明示してお知らせします。締め切りまでに保護者から変更・お休みの連絡がなければ、提案した日時で予約が決定します。締め切りは、判断に十分な余裕があるように、原則としてお知らせから3日以上あと、かつ授業日の2日前までに置きます。
  4. 塾からのお知らせがなかった場合、または判断の余裕がないまま直前に提案した場合は、保護者はその予約を無効（取消し）にでき、キャンセル料金はかかりません。ただし、事前に当事者の間でその日時について相談して同意していた場合（翌日の授業を希望して登録した場合など）は、時間的な余裕がなかったことを理由にしません。
  5. 未承認の将来月の学習計画や日時候補を表示する場合は、実施承認済みの授業予約と明確に区別します。指導計画承認書（期間・科目・回数・単価）の承認は、無回答・既読・期限経過だけでは成立しません。
  6. 前日23時は無料取消し期限です。期限後に新しく予約する場合は、その時点から適用されるキャンセルポリシーも示して承認を得ます。
  7. 将来の固定曜日・時刻の枠は、別途約束しない限り保証しません。

キャンセルポリシー（第8～13条）

授業の取消しや欠席・遅刻・日時変更により、予約していた授業時間のうち実施されなかった時間にかかる費用を「キャンセル料金」とします。無料で取り消せる期限、負担率、免除、塾側の都合による例外は以下に定めます。オンライン授業が接続不良で中止になった場合は、この章ではなく第17条で計算します。第17条で計算した時間に、この章のキャンセル料金を重ねてかけることはありません。

第8条 予約のお休みと新しい予約

  1. 保護者は、授業日の前日23時まで、予約した授業を無料でお休み（取消し）にできます。行わない授業の授業料もキャンセル料金もかかりません。塾の承諾は必要ありません。保護者が個別指導条件書で生徒本人からの連絡を認めている場合は、生徒本人も同じ連絡ができます。キャンセル料金が生じる連絡は、保護者にもお知らせします。
  2. お休みの連絡が指定のページ・LINE等の窓口に到達した時点で、元の予約は取り消されたものとして扱います。担当者が読んだ時刻や後から記録した時刻を理由に、キャンセル料金を上げることはありません。
  3. 予約済みの授業を取り消して、別の日または別の時刻に授業を希望する場合は、元の授業とは独立した新しい予約として、第7条に従って申し込むことができます。取り消した授業の予約と、新しく成立した授業の予約は、別々のものとして扱います。
  4. お休みの意思を明示しない連絡（別の日時が空いているかの問い合わせなど）は、予約の取消しとして扱いません。元の予約を取り消して別の日時で授業を希望する場合は、元の予約を取り消す旨を必ずお伝えください。
  5. 予約を取り消した場合、取り消した分の授業を別の日時で実施することは保証しません。講師や教室の空きがないときは、新しい予約をお受けできないことがあります。取り消した元の予約が自動で復活することもありません。
  6. 前日23時を過ぎてから元の予約を取り消す場合、または予約していた日時の授業が実施されなかった場合は、原則としてキャンセル料金が発生し、第9条によります。取り消した予約の代わりに別の予約をした場合であっても、元の予約の取消しについてキャンセル料金が発生します。同日の開始を遅らせる場合の未実施時間は第10条によります。

第9条 キャンセル料金と負担率

  1. 前日23時を過ぎてから、生徒側の事情で予約した授業の全部または一部が行われなかった場合、行われなかった時間（以下「未実施時間」）についてキャンセル料金がかかります。未実施時間は、元の予約時間の範囲内で数えます。
  2. キャンセル料金は「未実施時間に相当する授業料×負担率」で計算し、10円未満を切り捨てます。「未実施時間に相当する授業料」とは、その予約で合意した授業料と時間をもとに、未実施時間の分を時間に比例して計算した額です。例えば、予約していた90分4,500円のうち30分が未実施となった場合、相当する授業料は1,500円です。
  3. 負担率は、未実施時間に相当する授業料のうち保護者がキャンセル料金として負担する割合であり、連絡を受け付けた時刻によって、100％を上限として次のとおり定めます。
連絡の時刻 負担率
前日23時まで 0％
前日23時を過ぎ、開始3時間前まで 25％
開始3時間前を過ぎ、開始時刻より前 100％－75％×開始までの残り分数÷180
開始時刻以降、または連絡なし 100％
  1. 前日23時ちょうどまでを無料とし、この規定を他の時間帯区分より先に適用します。ページ・LINE・メール等の受付時刻を使い、塾が読んだ時刻や後から入力した時刻を理由に負担率を引き上げません。
  2. 同じ時間に、授業料とキャンセル料金の両方をかけることはありません。明細では、実施した分の授業料とキャンセル料金を分けて示します。
  3. キャンセル料金は予約ごとに計算します。別日時の新しい予約は別の予約として扱い、新しい予約を取り消した場合も、その予約について本条により計算します。複数の連絡や変更が重なる細かな場面は、事実を確認して個別にご説明します。

第10条 同日の開始を遅らせて予約し直す場合

  1. 元の予約のお休みは第8条により受け付けます。同日の別時刻に授業を希望する場合は、終了時刻、担当講師、他の授業を確認し、新しい予約について双方で合意します。
  2. 無料期限後の予約変更で、元の予約時間と新しい予約時間が重なる場合、元の予約時間のうち実際に指導した時間を除いた未実施時間にだけ、第9条のキャンセル料金を適用します。実施分の授業料は第6条によります。元の予約枠の同じ時間に授業料とキャンセル料金を重ねません。
  3. 新しい予約が成立しなかった場合でも、明示的に取り消した元の予約は復活しません。元の予約を残したまま日時を相談していた場合は、元の予約に遅刻・欠席した分を第9・11条により扱います。
  4. 変更後の日時、元の予約の未実施時間、新しい予約の授業料と見込み合計額を示し、実施前に承諾を得ます。

第11条 遅刻した場合

  1. 第10条で開始を変更した場合を除き、遅刻しても授業は予定の終了時刻に終わります。
  2. 遅れた時間は未実施時間として第9条で計算し、実際に行った時間は授業料として計算します。
  3. 遅れることが分かったら、その時点で到着の見込みをお知らせください。連絡がない場合の負担率は100％です。
  4. 到着の見込みよりさらに遅れた分は、改めて連絡を受けた時刻の負担率、追加連絡がなければ100％で計算します。
  5. 遅刻・当日の変更が続く場合は、無理なく通える曜日・時間について保護者と相談します。

第12条 やむを得ない事情による免除

  1. やむを得ない事情により受講できず、早めに連絡し、事情を確認できる場合、申請によりキャンセル料金を免除することがあります。実施分の授業料は免除対象に含みません。
  2. 対象となる事情の例は、公共交通の運休・遅延、親族の葬儀、災害、重篤な体調不良で受診した場合などです。通常の体調不良は対象外です。連絡・申請の期限、確認資料、救急搬送等で連絡自体ができない場合の扱いは、個別にご説明します。
  3. 資料は確認に必要な範囲に限り、病名等の不要な情報は隠してください。取得目的、提出窓口、保存期間は事前に案内します。
  4. 塾は確認結果と理由を回答します。保留・訂正・返金は第14条によります。対象表にない事情も相談できます。

第13条 塾の都合による変更と休講

  1. 塾の都合で日時を変更するときは、できるだけ早く連絡し、変更後の日時を相談します。保護者・生徒にキャンセル料金はかかりません。
  2. 塾の都合で行えなかった時間の授業料は請求しません。別の日に授業を行う場合は、その実施分について合意した料金を請求します。
  3. 塾の都合による休講と、生徒側の都合による取消は、記録と明細を分けます。

第14条 請求と支払い

  1. 当月に実施した授業の料金、キャンセル料金、および事前合意した教材等の費用を集計します。家族で合算する場合も、生徒別の内訳を示します。
  2. 原則として翌月3日に請求を確定し、保護者ページでお知らせします。1日と2日は塾が内容を確認する期間です。
  3. 支払いは銀行振込に一本化し、現金での授受は行いません。授業料等の振込手数料は振込を行う保護者が負担します。支払期限は請求が確定した月の15日です。15日が土日祝日の場合は翌営業日です。
  4. 支払期限までの支払いが難しい場合は、事前にご相談ください。連絡なく未払いが続く場合は、連絡・確認のうえ、授業の一時停止などを検討します。
  5. 免除申請の審査中、または第7項の申出について塾が確認・回答するまでの間は、対象のキャンセル料金とそれ以外の金額を分け、対象部分の支払いを保留します。争いのない部分は通常の期限内にお支払いいただきます。回答後に請求する場合は、理由・金額と支払期限を別途お知らせします。この通知によって法令上の支払義務の有無が確定するものではありません。

  6. 確定後の訂正は、元の請求と訂正理由を残して通知します。支払済みの減額は、返金または保護者が了承した翌月請求への充当で対応します。塾から返金する場合の振込手数料は、振込を行う塾が負担します。返金は原則として翌月の請求への充当で精算し、保護者が振込を希望する場合は、確定した月の翌月15日までに振り込みます。保護者は返金予定日の確認や早期返金を申し出ることができ、塾は対応の可否と予定日を回答します。

  7. 保護者は、キャンセル料金の計算、適用条件または法令への適合性に疑問がある場合、対象の授業と疑問の内容を示し、保護者ページまたは指定のLINE等の窓口から説明・見直しを申し出ることができます。法令名の特定や専門家の意見書の提出を申出の条件とはしません。

  8. 塾は申出を受け付け、事実関係と算定根拠を確認し、受付から7日以内を目安に、確認結果と理由を記録の残る方法で回答します。回答後に支払う金額は、次の請求（翌月15日期限）にまとめます。請求に誤りがある場合、または法令上請求できない部分がある場合は、当該部分を訂正・除外します。それ以外の場合も、個別の事情を考慮し、キャンセル料金の全部または一部を減額・免除することがあります。支払済みの場合は第6項に従って精算します。
  9. この申出手続や塾の回答は、保護者の法令上の権利、消費生活センター等への相談、裁判その他の紛争解決手続の利用を制限しません。法令上無効となる部分について、塾の了承を無効の条件とするものではありません。

第15条 受講の終了と予定済み授業

  1. 保護者は、ページ・LINE・メール等で受講終了を申し出ることができます。翌月の指導計画承認書について双方が合意しない場合、翌月の受講契約は成立しません。
  2. 終了の申出があっても、保護者が希望する場合は、既に実施承認・予約されている授業を受講できます。塾は、受講を希望する予約と取り消す予約、最終受講日を確認します。
  3. 精算するのは、実施した授業の授業料、取り消した予約にキャンセルポリシーが適用される場合のキャンセル料金、および別途事前合意した教材等の費用です。これら以外の解約金・退会金等は一切請求しません。
  4. 取り消す予約は第8～13条に従います。前日23時までに取消しを受け付けた予約に、終了の申出を理由として新たな料金を加算しません。
  5. 塾が翌月以降の継続を行えない場合は、原則1か月前までに連絡します。急病・事故等は分かり次第連絡します。

第16条 教材と配布資料

  1. 塾が指導上必要と判断して用意する教材の費用は塾が負担し、授業料に含めます。継続使用する教材や塾専用教材も含め、追加の教材費を請求しません。
  2. 保護者または生徒側の要望により、指定された教材を別途用意する場合は、当該教材の費用を保護者が負担します。塾が手配するときは教材名と負担額を示し、保護者の事前承諾を得てから手配します。生徒の希望だけで追加費用を確定しません。
  3. 教材・資料は当面、配布のみとし、貸与は行いません。貸与を行う場合は、範囲・返却条件・紛失時の扱いを事前に合意します。教材を用意したことを理由に翌月以降の受講を義務付けたり、塾負担とした教材費を退会時にさかのぼって請求したりしません。
  4. 教材・配布資料は生徒本人の学習のために利用し、許可なく販売・公開・第三者へ提供しないでください。法令上認められる利用まで制限する趣旨ではありません。

第17条 オンライン授業と接続不良による中止

  1. 生徒側で端末、通信環境、カメラ、マイク等をご準備ください。使用サービスと接続方法は事前に案内し、必要に応じて接続確認を行います。
  2. 接続不良によって授業の継続が困難な場合は、授業を中止できます。中止する旨を相手方へ知らせ、中止時刻を記録します。接続手段が使えない場合は、LINEまたはメール等で連絡します。
  3. 生徒側の通信環境・端末等の不具合で中止する場合、予定開始時刻から中止時刻までは通常の授業料で計算します。接続の確認・復旧に費やした時間を含みます。中止時刻から予定終了時刻までは、その時間に相当する授業料の30％をキャンセル料金として計算します。中止後は授業のために待機し続ける必要はありません。
  4. 第3項の通常料金部分は1円未満、30％部分は10円未満を切り捨てます。同じ時間に第9条の通常キャンセル料金や他の授業料を重ねません。後日行う授業は別の予約として合意します。
  5. 塾側の不具合、または利用サービス全体の障害によって実施できなかった時間には、授業料もキャンセル料金も請求しません。中止前であっても、障害により実施できなかった時間を通常料金へ含めません。実際に実施した分だけを計算します。
  6. 開始前の中止、短時間の切断、原因が分からない場合は、原因不明のまま生徒側の不具合と扱わず、事実を確認して個別にご説明します。

第18条 教室利用と安全

  1. 塾は生徒の安全確保に努めます。生徒は設備・備品を適切に使用し、危険な行為をしないでください。
  2. 体調不良時は無理に受講せず、早めにご連絡ください。緊急時の連絡先を塾にお知らせください。
  3. 故意または重大な過失による設備等の破損・紛失については、事情を確認して相当額の負担を求めることがあります。
  4. 事故等の責任は原因と法令に基づき判断し、本規約によって塾の法令上の責任を一律に免除するものではありません。

第19条 連絡方法

  1. 指導計画承認書、予定、請求は保護者ページ等で案内し、登録された連絡先に通知します。日々の連絡はLINE等でも受け付けます。
  2. 日程、料金、受講終了など重要な内容は、双方が確認できる方法で記録します。電話・対面で決めた内容も、塾から控えを示します。
  3. 連絡先が変わった場合はお知らせください。ページを利用できないときは、指定のLINEまたはメール（mugilives@gmail.com）へご連絡ください。
  4. 生徒本人からの欠席・遅刻等の連絡は、保護者が認めた範囲（前日23時までの無料のお休みなど）で受け付けます。認める範囲は個別指導条件書で定め、キャンセル料金が生じる連絡は保護者にもお知らせします。

第20条 情報の取り扱い

  1. 氏名、学年、学校、連絡先、成績、授業・宿題の記録、契約・請求・入金の記録および事前に説明して取得する面談等の録音を、指導、学習支援、連絡、契約と請求の管理に利用します。
  2. 管理にはCloudflare（台帳・ファイルの保管）およびGoogle（メール・カレンダー）の外部サービスを利用します。
  3. 講師には指導に必要な担当生徒の情報を共有し、料金・請求や免除申請の受診資料を、指導に不要な講師へ見せない運用とします。成績の共有範囲は実際の権限設定とそろえます。
  4. 法令に基づく場合や適法な業務委託等を除き、同意なく個人情報を第三者に提供しません。必要な安全管理を行い、保存期間を定めます。
  5. 記録に誤りがある場合は訂正を申し出ることができます。契約終了後の契約・請求記録等は、精算と税務に必要な期間（最長7年）保存します。免除の確認に使った資料は、確認が済み次第速やかに削除します。

第21条 保護者ページの利用

  1. 保護者はパスワードと生徒の専用リンクを適切に管理し、契約・受講に関係のない第三者へ共有しないでください。不正利用が疑われる場合は速やかに塾へご連絡ください。
  2. 家族内で共有する場合は、契約者と承認権限を持つ方を確認します。承認操作の際は、その方が内容を確認してください。
  3. 設定・再設定の方法はページ等で案内します。利用できない場合の連絡手段は第19条によります。
  4. アカウント共有等があったことだけを理由に、塾の責任を一律に免除するものではありません。

第22条 実績や口コミの広報利用

成績推移、写真、体験談、口コミ等を広報に使う場合は、利用内容、掲載先、表示する情報、期間等を示し、受講の同意とは別に同意を得ます。匿名でも個人が推測できる場合があります。同意しないことによって受講条件を不利に変更しません。利用停止は指定窓口に申し出ることができます。

第23条 禁止事項と契約解除

  1. 暴力、暴言、威圧、著しい迷惑行為、許可のない授業の録音・録画・撮影・配信・公開、教材の不正利用など、指導や他者の権利を侵害する行為は禁止します。
  2. 契約違反がある場合は、相当な期間を定めて是正を求め、改善されないときに契約を解除できます。
  3. 暴力など安全や信頼関係に重大な支障を与える場合は、直ちに受講を停止し、契約を解除することがあります。具体的な適用は事情に応じて判断します。
  4. 終了時の料金は第15条に従い精算します。

第24条 規約の版と変更への同意

  1. 適用する規約は、保護者が同意した版の全文です。掲載ページを更新したことだけで、過去に同意した内容を置き換えません。
  2. 塾は同意した版、対象となる計画、同意者、日時、方法を保護者ページに記録し、保護者はいつでも同じ内容を保護者ページで確認できます（控え）。記録は精算と税務に必要な期間（最長7年）保存します。
  3. 条件を変更する場合は、変更点と適用時期を翌月の計画等とともに示し、同意を得た契約から適用します。
  4. 同意しない場合、変更後の条件による契約は成立しません。受講継続の可否や終了日を確認し、既に成立している契約と精算は従前の合意に従います。
  5. この版は2026年11月1日から適用します。適用日より前に成立した契約と精算は、従前の合意によります。

第25条 協議と法令上の権利

本規約に定めのない事項や疑義は、双方が誠実に協議します。本規約は、法令により認められる取消し、解除、損害賠償請求その他の権利を妨げるものではありません。

接続不良による中止の計算例（第17条）

生徒側の接続不良により90分4,500円の授業を開始30分後に中止した場合、開始から中止まで1,500円＋残り60分相当3,000円の30％＝900円、合計2,400円です。これは通常の直前取消しの100％を適用する例ではありません。塾側・サービス全体の障害の場合は、未実施時間の料金は0円です。例えば最初の20分は指導でき、その後10分の障害対応を経て中止した場合、実施20分の1,000円のみを計算します。

免除の対象事情（第12条）
